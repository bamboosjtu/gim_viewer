# GIM Viewer

在本地浏览电网工程 GIM 文件。Windows 桌面版支持变电站、输电线路和独立设备，Android 预览版面向输电线路现场查阅。

[下载 Windows 0.2.1 预览版](https://github.com/bamboosjtu/gim_viewer/releases/tag/desktop-v0.2.1-preview) · [下载 Android 预览版](https://github.com/bamboosjtu/gim_viewer/releases/tag/android-v0.1.6-preview) · [全部发布](https://github.com/bamboosjtu/gim_viewer/releases)

## 下载后开始

| 平台 | 使用方法 |
| --- | --- |
| Windows x64 | 下载后完整解压 Portable ZIP，保留随包的 WebView2 运行时目录，运行 <code>GIM-Reader.exe</code>，打开本地 <code>.gim</code>。 |
| Android ARM64 | 支持 Android 10 及以上。解压发布附件并安装 APK，在应用内通过系统文件选择器导入本地线路 <code>.gim</code>。 |

## 功能

- **变电站与独立设备**　浏览 IFC、DEV/MOD/STL 的三维表示，通过工程树和搜索定位设备，查看分层属性和对应来源。
- **输电线路**　在地图上浏览杆塔、物理档和跨越对象，通过工程树与地图联动查看原始属性和来源。移动端支持现场定位、杆塔局部骨架预览和离线工程图。
- **本地工程管理**　解析、索引和缓存均在本机完成。暖开复用有效的工程缓存。在线底图需要网络，无底图模式可离线查阅工程。

产品行为与已知限制见[桌面规格](docs/software-spec.md)、[移动端规格](docs/mobile-spec.md)和[问题清单](docs/open-issues.md)。

## 性能基线

当前 README 的性能对照基线为源码提交 [`d21877f`](https://github.com/bamboosjtu/gim_viewer/commit/d21877f72c3a9b35092e63726f4f3ae98a6244a8)。数据来自 2026-11-24 的 Windows x64 Release 本地实测，使用固定 WebView2，视口为 2048 × 1082，设备像素比为 1.25。每个输入计划一次冷开和一次暖开，时间单位为秒。

| 测量范围 | 记录数 | 结果 |
| --- | ---: | --- |
| L1 线路，6 个工程 | 12 | 12 PASS |
| L1 变电，4 个工程 | 8 | 6 PASS、2 PARTIAL |
| L0 通用设计，48 个输入 | 96 | 78 PASS、8 PARTIAL、5 INPUT_ERROR、5 SKIPPED |

按样本标签、文件大小和冷暖状态对齐，116 条记录的结果分类与上一版一致。L0 批次总评为 FAIL：5 个损坏输入的冷开记为 INPUT_ERROR，对应暖开记为 SKIPPED。其余 106 条均有完整的测量与内存观测，其中 10 条仍保留工程内容缺口。后续更新按样本 SHA、场景和冷暖状态核对；新增 INPUT_ERROR、FAIL 或 INCONCLUSIVE 须先查明并解决。
