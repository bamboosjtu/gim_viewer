## Default Permission

User-selected private GIM import and cancellation

#### This default permission set includes the following:

- `allow-pick`
- `allow-cancel`
- `allow-check-location-permissions`
- `allow-request-location-permissions`
- `allow-get-position`
- `allow-get-window-state`
- `allow-set-immersive`
