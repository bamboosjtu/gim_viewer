## 指定提交对照的判定

- substation01 暖基础表示中位数：最终 6.29 s，b414a59 为 6.40 s、7b4d0fc 为 6.56 s，不能宣称启动加速。
- B1 暖基础表示中位数：最终 29.55 s，b414a59 为 26.82 s、7b4d0fc 为 28.52 s；最终分别约慢 10.2%/3.6%，范围重叠，但必须如实保留小幅变慢。同步场景提交累计中位数只相差约 34–43 ms，尚不能把全部站级波动归因于新增元数据。
- 当前没有保留新的整站启动性能优化。默认 DEV 拾取缺失、raw 浏览误走 L2 及全小构件消失按 Bug 修复保留；有界拾取减少原工作树新增热路径成本。两份提交本来缺失普通 DEV 拾取，不能以缺失功能的零成本作为等价功能优化基线。
- 选择固定路线每组 20 次尝试、18 次有效命中，最终 p95 427 ms，基线 487.1/491.9 ms；没有明显回退，但一次路线不证明稳定提升，也不是 20 个独立来源或 GPU 呈现验收。
- 临时细分选择埋点和不安全的 IFC 可见性捷径撤回。O-05/O-07 未关闭；迟到缓存回调覆盖 IFC 结束文字由 O-10 跟踪，没有通过更改产品状态让基准提前结束。
