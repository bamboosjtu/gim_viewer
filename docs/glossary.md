# 术语表

本表只定义文档中的固定含义，不重复具体规则。

| 术语 | 含义 |
|---|---|
| 来源 occurrence | 包内一次真实的文件/引用/装配出现；同一模板多引用是多个 occurrence |
| 来源图 | CBM 引用、DEV 实际装配、IFC 外露和文件引用的中立图，不等于展示树 |
| 对象证据 | 从来源记录提取的名称、类型、材料类型、工程编码、相数、真实装配边等 |
| 工程整体 | 施工/运维识别的一个设备、材料、构件或待确认集合；有稳定 `entityId` |
| 待归集合 | 身份或宿主不足、不能确认成一个整体的来源集合；不是设备 |
| 成员 | 一份来源对某个整体/待归集合的主归属；每份来源最多一个主归属 |
| 独立对象 | 不并入宿主整体的对象，如无真实装配边的独立端子箱、独立基础、舱内开关柜；可有安装/服务关系 |
| 表示 | DEV 网格、GLB、IFC 远景/区域/精化等可渲染对象；不是工程整体 |
| 表示绑定 | 用来源 ID 把工程整体/成员映射到 DEV/IFC 表示；不按邻近或同名匹配 |
| 粗表示歧义 | 一个合并表示覆盖多个整体，无法可靠拆分；不自动归给任一整体 |
| 三视图 | 设备材料清册、工程组成、来源三个投影；共用搜索和选择，不共用分组规则 |
| 工程组成 | 按建筑/安装工程组织的默认视图；节点是分组、整体或待归集合 |
| 设备材料清册 | 按目录类别、子类、名称模板盘点工程整体的投影；不决定实体边界 |
| 建筑推断 | 从 IFC 空间/交付名称/声明确定建筑、楼层、房间归属；不按 F 层级猜 |
| 空间推断 | 用源 Z-up 几何范围补充建筑轮廓、房间和户外区域的组成投影；不改实体身份 |
| 来源视图 | 按 CBM 引用、DEV 装配、IFC 文件/空间/外露对象组织的原始来源视图 |
| 目录 | 项目使用的 E/M/C 类别及目标粒度；不是国标编码 |
| 角色 | 对象在来源中的意义：object/part/fragment/container/detail/source_only/neutral_set |
| 分区 | 来源到整体/待归/仅来源的完整、互斥归属；有守恒校验 |
| 冷启动 | 无有效工程缓存，需解压、解析并生成派生缓存 |
| 暖启动 | 复用同一源和 profile 的有效缓存；语义/L0/IFC 命中仍需逐项记录 |
| 严格暖 | 所需语义、L0、L1 和 IFC 均命中，无冷编译 |
| First usable | 首个可浏览几何/视图可交互的产品时刻，不等于全站完成 |
| 当前视图 | 当前相机所需档位完成；不等待全站基础表示 |
| 基础表示 | 每个 occurrence 的 L0/L1 或明确空/不支持/失败终态 |
| Spatial | IFC 空间节点、对象、宿主链和关联证据的快照/构建过程 |
| bim-lod | IFC 浏览 LOD0/1/2 策略；L0 包围盒、L1 轮廓、L2 显式精化 |
| 自动定位 | 树/搜索选择后是否移动相机；三维点击默认不自动定位 |
| 隔离 | “仅看选中”的临时可见性范围；不改变源图层开关 |
| 证据边界 | 某结论能证明什么、不能证明什么；不同构建/输入/缓存不能互相替代 |
| 九工程 | 4 个基础变电样本加 5 个扩展变电工程（A3-1、B1-1–B1-4），用于工程实体/三视图对照 |
| 十样本 | 2026-11-06 快照的 4 个变电加 6 个线路样本；后续快照未全部复测，不等同“九工程” |
| L0 / L1 / L2 | DEV 几何或 IFC 浏览的表示档位；L0 基础轮廓、L1 可见细节、L2 用户显式精化 |
| PASS / PARTIAL / INCONCLUSIVE | Benchmark 运行结论：完整通过 / 有证据支持的局部结果 / 证据不足；PARTIAL 不等同 PASS |
