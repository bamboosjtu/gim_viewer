# GIM 容器结构分析

目标：确认 .gim 是什么容器外壳。

> **2026-08-24 复核（10 样本）**：容器层结论在 6 线路 + 4 变电、4 种变电导出软件 + 2 种线路导出软件上全部复现，且新增头部元数据字段布局发现。证据：`_generated/container-survey.csv`（`desktop/scripts/gim_survey/container_verify.py` 生成）。

## 1. 样本范围

| 样本 ID | 类型 | GIM 魔数 | 压缩格式 | 压缩数据偏移 |
| --------------- | ---- | -------- | -------- | -----------: |
| demo-substation | 变电 | GIMPKGS | 7z | 784 |
| substation02 | 变电 | GIMPKGS | 7z | **776** |
| substation03 | 变电 | GIMPKGS | 7z | **776** |
| substation04 | 变电 | GIMPKGS | 7z | 784 |
| demo-line1 | 线路 | GIMPKGT | 7z | 784 |
| line02 | 线路 | GIMPKGT | 7z | 784 |
| line03 | 线路 | GIMPKGT | 7z | 784 |
| line04 | 线路 | GIMPKGT | 7z | 784 |
| line05 | 线路 | GIMPKGT | 7z | 784 |
| line06 | 线路 | GIMPKGT | 7z | 784 |

**10 样本结论**：

- 魔数与工程类型的对应规则在全部样本成立：`GIMPKGS`=变电、`GIMPKGT`=线路。
- 压缩格式全部为 7z，仍未观察到 ZIP。
- payload 偏移出现两种取值：784（8 个）与 776（2 个）。776 的两个样本恰好来自不同导出软件
  （Bentley Substation / BIMBase电力套件），而 JinQu 与 SDDP 样本为 784。
  当前证据支持"偏移由导出软件决定"，但样本不足以确定精确规则。

## 2. Header 固定布局（本轮新发现）

Header 不是纯魔数区，而是含多个固定偏移的元数据区段（UTF-8 编码、`\0` 填充）：

| 偏移 | 字段语义 | 示例 |
| ---: | --- | --- |
| 0 | 魔数 `GIMPKG` + 类型位（S/T），共 7 字节 | `GIMPKGS` |
| 16 | 工程/项目文件名（通常含 `.gim` 后缀） | `内部编号-变电站01-竣工图-日期.gim` |
| 272 | 设计单位 | `某设计院` / `Bentley Engineer` |
| 336 | 业主/建设单位 | `某业主单位` / `Bentley Systems` |
| 592 | 导出软件 | `JinQu_GRevitTools` / `SLW3D架空送电线路数字化设计系统7.0.2026.0701` / `Bentley Substation` / `BIMBase电力套件` / `变电数字化设计平台 (SDDP)` / `输电线路数字化勘测设计系统` |
| 720 | 导出日期时间（ASCII，格式随软件变化） | `2026-06-17 16:14` / `2021-46-08 02:46` |

已观察到的字段内容不可靠性：

- 工程名字段可能与外部文件名不一致（demo-substation 内部名带竣工图编号；substation04
  内部名为"某110kV变电站（header 内部名与外部名不一致案例）"，与文件名"变电站04"完全不同——注意该样本
  header 自称 110kV，实际工程等级待 CBM 层核实）。
- 设计单位/业主字段可能为空或互相错位（SLW3D 系线路样本 owner 一律为软件厂商占位值，
  疑似工具厂商占位而非真实业主）。
- 日期字段长度不定，末尾可能残留下一字段的字节（如 `21:077`），解析时需按 `\0` 截断并容忍脏尾。
- 各字段区段之间为 `\0` 填充；区段起点固定，但区段总长随内容变化。

## 3. 对解析器的影响

- 解析器应继续采用"在头部之后 1MB 窗口内搜索 7z 或 ZIP 签名"的方式定位压缩 payload，
  **不应改成固定 `offset=784`**（776 反例已在册）。
- Header 元数据可用于诊断展示（导出软件溯源），但**不能作为工程名的 ground truth**；
  工程信息应以解压后 CBM 层内容为准。

## 4. 待验证问题

- 是否存在 ZIP payload 的 GIM（当前 0/10）。
- 偏移取值是否只有 {776, 784} 两类，还是随软件版本连续变化。
- 头部字段布局是否在更早版本的导出工具中存在（Bentley 2021 样本布局一致，说明至少自 2021 年起稳定）。
