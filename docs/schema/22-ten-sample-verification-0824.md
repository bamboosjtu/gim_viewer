# 十样本 GIM Schema 基线

> 本文汇总 4 个变电样本和 6 个线路样本的可复核格式事实，作为解析器和 UI
> 边界的证据。它不是性能报告，也不记录按日期排列的实施过程。统计输出来自
> `desktop/scripts/gim_survey/` 的容器、文件清单、引用链、几何和线路格式扫描。

## 1. 跨样本成立的规则

| 规则 | 样本支持度 |
|---|---:|
| `GIMPKGS` 表示变电，`GIMPKGT` 表示线路 | 10/10 |
| payload 为 7z，压缩数据偏移必须搜索定位 | 10/10 |
| 四目录结构存在，目录大小写随工程类型变化 | 10/10 |
| 三层文件引用没有硬缺失 | 10/10（约 35 万条引用） |
| 文本文件使用 `KEY=VALUE` 变体，键名比较大小写不敏感 | 10/10 |
| 线路 MOD 属于四类文本格式族 | 6/6 |
| 线路 POINT=5 token、LINE=2 token、G 记录=6 token | 6/6 |
| `SOLIDMODELn` 与 `TRANSFORMMATRIXn` 一一对应 | 10/10 |
| 线路 MOD 不含变换矩阵字段 | 6/6 |
| 线路 `entityName` 与几何 kind 映射稳定 | 6/6 |
| STL 通过 PHM 引用 | 9/9（一个变电样本没有 STL） |

这些规则支撑当前容器识别、大小写归一化、线路 MOD parser、PHM 引用链和
变电几何 manifest 的实现。

## 2. 导出工具差异

以下差异是样本事实，不应被硬编码为单一 GIM 标准：

| 维度 | JinQu 类 | Bentley 类 | BIMBase 类 | SDDP 类 | 线路类 |
|---|---|---|---|---|---|
| payload offset | 784 | 776 | 776 | 784 | 784 |
| DEV:PHM:MOD 数量 | 1:1:1 | 1:1:0.53 | 1:8.6:6.7 | 1:0.99:3.0 | 不适用 |
| PHM 矩阵 | 多为单位阵 | 单位阵 | 大量非单位阵 | 少量非单位阵 | 多为单位阵 |
| STL 角色 | 二次柜 | 可能没有 | 一次设备 | 设备几何 | 金具/线路附件 |
| primitive 家族 | 14 类常见 | 有新增类 | 有新增类和 `.gl` | 有新增类 | 四类文本族 |
| SCH/STD/SLD 三件套 | 常见 | 可能缺失 | 可能缺失 | 常见 | 不适用 |

因此当前解析器必须搜索签名、递归 PHM 并防环、对 primitive 保留弱 schema
回退、对 `Visible` 和实体名做大小写归一化，不能把单一工具的数量比例或
字段布局当作必然规则。

## 3. 当前实现对应关系

- 容器层：搜索 7z/ZIP 签名，不写死 payload offset；Rust 解压逐 entry 落盘。
- CBM 层：按工程类型选择引用键，实体名、目录和文件名比较大小写不敏感。
- 变电几何：PHM 允许嵌套并使用 visited 防环；DEV/PHM/CBM/SUBDEVICE 的列主序
  变换在实例级累积，PHM `COLORn` 与 `SOLIDMODELn` 一一对应。
- 变电 XML MOD：开放式 primitive 分发，已知类型强解析，未知类型保留弱 schema
  或空结果，不因单个 primitive 阻塞其它设备。
- 线路 MOD：HNum、Point/Line、Section-KV 和 Key-Value 四类格式由运行时按需
  解析；CODE 保留来源码，不仅凭数字猜业务名称。
- 线路地图：`BLHA` 作为塔位中心坐标，`MATRIX0` 提供挂点偏移候选；same-point
  和 inter-point 分开处理，实验性弧垂与可见采样共享交互几何。
- 属性展示：属性集、工程量、材质、分类、类型等 IFC 详情由 Fragments
  `getItemsData()` 按需读取，不进入 Spatial Core 的长期索引。

## 4. 仍需保留的格式边界

1. 变电存在 `.gl`、Boolean/Wire/Cable 等低频几何类型；当前按引用可达性和
   parser 支持情况处理，不把所有新类型强行映射成已有 primitive。
2. PHM 可能包含平移、旋转、镜像和多层嵌套；渲染必须使用完整累积矩阵，不能
   默认 IDENTITY。
3. `COLOR` 的 A 通道刻度随导出工具变化；当前使用文件级 `max(A)` 判定百分制或
   字节制，并将 A=0 作为不透明哨兵。
4. 线路 `KVALUE`、`MATRIX0` 的工程公式和单位仍未形成验收规范；地图曲线只作
   视觉示意，产品决策统一维护在 [dev-log.md](../dev-log.md)。

## 5. 证据与维护边界

- 详细字段、引用链和几何统计见本目录的 00–16、19、20 号文档；它们记录样本
  事实和格式边界，不承担产品待办。
- 新样本只需补充样本台账和对应统计，确认跨工具成立后再更新本基线及解析器。
- 性能数字、单次运行日志、缓存 A/B 结果和实施过程不写入 Schema 文档，统一
  由项目外部诊断或 [dev-log.md](../dev-log.md) 的结构化条目管理。
