优先级：
P0 为正确性或核心流程阻断，P1 为主要效率、可维护性或拟交付核心需求，P2 为增强或需要场景确认的候选。状态分为待核验、待开发、待决策；列入不代表已排期。同一问题只使用一个 ID，新增证据原地更新，不追加阶段叙事。

## 桌面实现问题

当前没有未关闭的编号事项。已接受的性能/能力边界见[性能](performance.md#已接受的当前边界)，逐项判定与关闭理由见[复核](open-issues-review.md)。

现行模板共享和 IFC/Spatial Worker 已存在，不作为待开发项重复立项。

大型 IFC 几何实验未关闭的具体问题：完整 02 原路径在 120 秒窗口内尚未提交钢结构 LOD0；自适应候选虽提交预览，实际鼠标目标板件 ExpressId 66438 被另一 MEMBER 566436 遮挡/命中，未完成整站单对象精化验收。不能据此认定 identity 映射错误，也没有足够证据将原因归结为单一坐标或相机问题。视距候选单轮最慢不可中断轮廓构建约 54.4 ms，超过 2 ms 软预算；降低三角面并未同时降低 draw calls。对象精化首请求仍须读入并 OpenModel 整个源文件，局部实验约 16 秒、WASM heap 容量约 808 MB，不能宣称任意对象均可即时精化。结果保留在 `output/ifc-geometry-breakthrough/`，失败不提高超时重跑。跨表示位置与复杂开洞正确性仍需逐对象证据，不使用拟合 T。

小 IFC 的真实 Tauri/WebView 替换已有局部验收证据：独立验收包封装两个未修改的真实 IFC，目标文件 575,414 bytes、SHA-256 `3cfe2f6927511badc4b5ae112a71e994404b83139102d0ea63c4b2be8f7f927d`；语义冷/暖路径均保持同一 GlobalId/ExpressId，LOD0/LOD1/LOD2 包围盒中心误差约 4.21 微米，精细高亮与属性沿用原 SelectionRequest。此证据只覆盖该对象和输入，不证明全站跨表示等价。

substation02 的 DEV 单工作单元仍有不可中断长尾，循环间检查点不能覆盖内部序列化。原生语义持久化已独立于该重任务，暖启动验证不代表完整几何 HIT；缺失或未完成的几何继续按原回退路径处理。连续输入响应观测不覆盖全部后台工作；进程内存驻留仍较高，完整转换 Worker heap 尚无精确公开测量。 性能指标见 [性能](performance.md)。
