## 5. 保留判定与未达标项

没有保留或宣称新的整站启动加速：小站差异很小，大站候选中位数略慢且范围重叠。保留的是默认 DEV 拾取缺失、错误自动 L2 raw 回退及全小构件消失等修复，并以有界实现限制新增成本；临时选择细分埋点撤回。严格样本入口修复没有产品运行时开销。
O-02：B1 冷/暖基础表示仍超 60/20 s；O-05：自动 L1、隔离、图层及增量来源的完整原生组合边界仍待验收；O-07：选择响应与已缓存属性 DOM 未通过；O-10：迟到缓存回调覆盖 IFC 结束状态仍保留。实例化默认关闭，帧间隔 p95/p99、固定路线、十次工程切换和全样本三次冷暖/持续内存矩阵未完成，不以本轮关闭。
