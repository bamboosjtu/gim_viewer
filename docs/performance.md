# 性能基线

本文件记录**当前可复现的测量结果、判定边界和未达标项**。测试步骤、冷/暖定义与报告模板见 [性能测试指南](meassurement.md)；实现机制见 [架构](architecture.md)；未关闭的缺陷与验收缺口见 [问题与限制](open-issues.md)。

## 1. 本轮测量口径

### 1.1 环境与构建

| 项目 | 值 |
|---|---|
| 日期 | 2026-10-25 |
| 源码 | `7b4d0fc` 工作树（含本轮死代码与文档清理；运行时行为未改） |
| 构建 | Vite 开发服务器 `http://127.0.0.1:14317/`，未压缩、HMR 开启 |
| 浏览器 | Headless Edge 156.0.0.0（Chromium 156），独立临时 profile |
| 图形 | ANGLE D3D11，NVIDIA Quadro P4000；1600×900，DPR 1 |
| 主机 | Windows，12 逻辑核，约 32 GiB 内存 |
| 并发 | 每次只运行一个浏览器和一次打开；测量期间不运行构建、测试或其他基准 |

这是**浏览器开发模式基线**，不是 Release/WebView2 验收：没有原生 7z/SQLite 解压、没有独立应用数据目录、没有固定 WebView2 运行时，代码也未压缩。数字不能与历史原生 Release 结果直接比较，也不能据此宣称原生 SLO 通过。本轮未执行原生 Release 的三次冷暖矩阵。

### 1.2 测什么

- 每个样本使用全新的浏览器 profile；通过页面“打开 GIM”入口选择同一份 `demo/<sample>.gim`，不修改样本。
- **冷启动**：新 profile 下的首次打开，包含 WASM 解压、语义解析、索引构建、IFC 转换和 DEV 编译。
- **暖启动**：同一 profile 重启浏览器后再次打开。浏览器模式没有桌面 SQLite 语义缓存；IFC LOD 派生缓存位于 IndexedDB。本轮一次 profile 复用没有产生 IFC 命中（见 §3），因此**不把该次记录当作有效暖启动，也不报告暖启动成绩**。
- **First usable（变电）**：`productMoments.interactive`，即首个可用 IFC 提交、工程可交互。
- **Current view**：`productMoments.devCurrentViewSettled`；**基础表示完成**：`productMoments.devBaseRepresentationsSettled`；两者都允许已结束的失败，并单独列出失败数。
- **线路 First usable**：应用内 `线路工程可交互` 标记；线路没有分阶段 DEV 几何，Current/Full 不单列。
- 外部 wall 时间从文件选择事件到页面状态出现，包含 1.5 秒稳定等待，只用于核对，不替代应用内时刻。
- 一次运行只代表该次样本/缓存状态，不替代三次冷暖矩阵或中位数/最大值。

## 3. 暖启动状态

本轮只做了一次同一 profile 重启打开 substation04 的检查：IFC 派生缓存命中为 0，所有 IFC 重新转换；First usable 8.84 s、基础表示 9.74 s、全部 IFC 39.70 s，均慢于同一 profile 的冷运行。该结果不能标为有效暖启动。

原因边界：

- 浏览器模式没有桌面 SQLite 语义缓存；DEV 派生缓存也依赖桌面项目身份，不能按原生暖启动口径恢复。
- Headless 浏览器在 `taskkill /F` 结束前可能未把 IndexedDB 写入全部落盘；本轮没有用优雅关闭复验，不能据此断言浏览器缓存的真实暖能力。
- 因此本文件不报告暖启动 SLO，也不把该次记录与冷启动表混算。原生暖启动仍以独立 Release、同一 profile、缓存写入完成后的重启为准，见 [性能测试指南](meassurement.md) §4。

## 4. 当前实现的相关事实

以下事实用于解释测量，不重复架构契约：

- **分级**：IFC 使用 `bim-lod`，LOD0/LOD1 在转换 Worker 内先后提交，LOD2 仅在属性面板显式请求；DEV 自动策略只返回 L0/L1，首次进入 L1 需投影 ≥40 px，已处于 L1 时 ≥30 px 保持、低于 30 px 回 L0；像素上限为视口较大边的 2 倍。L2 只由明确精化进入。
- **并发**：DEV Worker 池按逻辑核约 60% 取 2–8 个；IFC 未完成时最多两个 DEV 编译槽，首个 IFC 完成后放开到池上限。普通选择、搜索和相机靠近不打开 L2。
- **缓存**：语义、DEV 几何、Spatial、Fragments 和 IFC LOD 分域失效；DEV 模板键包含源身份、DEV 路径和 LOD；IFC LOD 缓存在浏览器使用 IndexedDB，桌面使用原生派生缓存。暖启动必须同时核对缓存写入完成。
- **连接构件**：有源证据的连接网格先于普通 Fragments 导入分批提交，独立可选缓存凭据；对象总数不等于电气导线条数，端点归属多义时不自动选择。
- **大 IFC**：默认仍完整转换并排到队尾；设置项 `ifc.skipLargeFiles` 开启后才跳过非关键超大文件，状态栏显示跳过数。
- **静态容器**：Scene 与 MOD/STL 图层关闭局部矩阵自动重算，避免每帧强制更新静态子树；动态对象和锚点更新仍传播。该机制不改变 draw calls 或几何内容。

## 5. 判定与未达标项

本轮浏览器开发模式相对**既有原生目标**（冷启动工程可操作 ≤10 s、首个有效画面 ≤15 s、当前视图 settled ≤30 s、基础表示 settled ≤60 s）只能作方向对照：

- substation04 的 First usable 8.05 s、当前视图 9.11 s、基础表示 8.63 s 在该次运行中低于目标；substation02/03 的当前视图与基础表示也低于 30/60 s，但不能据此宣称 Release 达标。
- substation01/02/03 的 First usable 分别为 17.40/15.45/24.24 s，超过 10 s；substation03 的全部 IFC 98.64 s，仍是长尾。
- line02 的 First usable 11.70 s 超过 10 s；其余线路样本在 10 s 内。
- substation02 仍有 34 个失败、561 个空源、807 个未知范围；substation01 有 52 个、substation03 有 38 个、substation04 有 110 个未知范围。失败和未知范围不能被“已显示数”掩盖。

未完成/不能由本轮证明的项目：

1. 原生 Release 三次冷启动及对应暖启动矩阵、固定相机路线、帧间隔 p95/p99、6 GiB 进程树私有内存峰值和 10 次工程切换。
2. 浏览器有效暖启动（需优雅关闭并核对 IndexedDB 写入；本轮未完成）。
3. 普通点选端到端 p95、已缓存属性摘要 p95 和 30 秒真实交互路线；本轮没有完成可复现的选择时延采集。
4. 连接构件完整源长尾、旧远景缓存端点补采、多义/缺失归属。
5. 实例化试点仍默认关闭；其绘制收益与基础表示回退的既有对照不因本轮测量改变。

这些问题分别由 [open-issues](open-issues.md) 的 O-01/O-02/O-07 与 L-06 等条目跟踪；本文件不复制其验收历史。

## 6. 复现

浏览器开发模式：

1. 在 `desktop/` 启动 `npm run dev`，确认监听 `127.0.0.1:14317`。
2. 使用独立 headless Edge profile 打开首页，等待启动完成（`__gimAppState` 存在、加载遮罩隐藏），点击“打开 GIM”，对隐藏的 `#gim-file-input` 设置 `demo/<sample>.gim` 并派发 `change`。
3. 轮询 `src/utils/perfTimings.ts` 的 `perfBenchmarkSnapshot()` 与 `perfSnapshot()`；变电等待 `devBaseRepresentationsSettled` 与 `allIfcReady` 均非空，线路等待 `线路工程可交互` 标记或底部杆塔摘要。
4. 每个样本使用新 profile，冷启动不要复用上一轮 profile；记录原始 JSON、截图、环境与失败数。
5. 测量期间不要并行构建、测试、其他浏览器或大型应用。

本轮临时 harness 位于本地 `.tmp/perf/`（Git 忽略，不随仓库发布）；原始 JSON 与截图归档在 `output/perf/2026-10-25/`（同样被 Git 忽略）。正式原生验收按 [性能测试指南](meassurement.md) 执行 Release 构建、独立验收缓存和三次冷暖矩阵。

- 本文件只保留当前实测与当前边界；历史实验记录、已回退路线与逐窗口采样见 [探索记录](impl/explorations.md)。
- 机制、缓存版本与调度契约以 [架构](architecture.md) 为准；缺陷与验收状态以 [问题与限制](open-issues.md) 为准。
