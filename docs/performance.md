# 性能基线

本文件记录桌面原生 Release 的当前性能基线、测量口径和未达标项。方法见[测量指南](meassurement.md)，缺陷见[问题清单](open-issues.md)。本文件替代 `0.1.x` 的旧矩阵，旧数据不再作为当前构建的通过证据。

> **版本边界**：矩阵使用 `0.2.0` 构建，提交 `8c2aab5`（工作区 dirty），源码指纹 `13b73f5bae0ce62c036590ec2eba059d904c61cd7b540e101aaaf12a29a39128`，EXE SHA-256 `ac7d068aa2d39d76855f7423f7e7cf2aa5808d429cc4077d274a94cf8ac34dc6`，Fixed WebView2 SHA-256 `1bc71a6d464da1cd3f63ac1ff0d1b748f528aa8b3957b5e3a7f9ae28d6df7071`。测量日期 2026-11-03。矩阵后修正了 E16 的“二次设备”泛词误吞建筑名、B1-3 partial 来源命中校验和 B1-4 超限缓存的显式禁用，并重建最终验收包（源指纹 `0a8f3882ea82`）；这些修正不改变几何路径，最终包仅对 substation04 做了冷启动烟测（基础表示 11.72 s、全部 IFC 27.21 s），未重跑整张矩阵。

## 1. 结论

- 六个样本的冷基础表示进入 60 s 内：substation01–04、A3-1、B1-2。
- **B1-1 冷基础表示 464.89 s**，比旧基线的 234.76 s 明显回退；B1-3 145.60 s，超过 60 s；B1-4 在 1,500 s 窗口内仍未完成。
- 有效暖启动中，B1-1 基础表示 **28.53 s**，超过 20 s 目标；其余有效样本中位 2.52–12.02 s。
- **B1-3 暖启动没有有效轮次**：缓存只恢复 7,966/19,225 条来源和 7,105/18,259 个整体，随后重新解析，单轮约 120 s。
- **B1-4 工程实体缓存写入失败**：`工程缓存无效：plain size`；冷运行 15,181/15,526 个 occurrence 已显示，基础表示和当前视图未完成，仍有 227 个 occurrence 待提交、2 项缓存待写。
- 本轮**没有重跑**三次真冷、低配矩阵、固定路线 20 次选择交互和工程切换；不能把本文件写成完整验收通过。

## 2. 构建、环境与口径

| 项目 | 值 |
|---|---|
| 主机 | Windows 11 26300，Intel i7-8700（6 核 / 12 逻辑核），63.8 GiB，NVIDIA Quadro P4000 |
| 运行时 | 随包 Fixed WebView2 155.0.4283.62；验收 identifier 的独立数据根 |
| 窗口 | 原生外框 1600×900，移出屏幕但不最小化；未做 CPU 限速 |
| 并发 | 逐次运行；矩阵期间不同时构建或跑测试 |
| 缓存 | 每样本独立 WebView profile；冷启动删除工程记录、提取目录、派生缓存和 profile，暖启动复用 |

时间单位为打开动作后的秒数，不含 exe 启动。First usable 取 `productMoments.interactive`（首个 IFC 可浏览）；导航 DOM 的 `navigationUiReady` 不当作输入延迟。基础表示取 `devBaseRepresentationsSettled`，当前视图取 `devCurrentViewSettled`，IFC 结束取 `allIfcReady`，空间索引取 `spatialSemanticReady`。

冷启动有效要求语义未命中、L0 冷编译、IFC 全部冷转换。暖启动有效要求语义命中、L0 冷编译为 0、IFC 全部 LOD 命中；有效暖还要求 Spatial 缓存命中。只命中 L0/IFC 但 Spatial 重建的轮次不写成完整暖。

## 7. 交互与未覆盖项

- 本轮未执行固定路线 20 次选择；旧 `0.1.x` 的 566.9 ms p95 不能迁移到 `0.2.0`。
- 未执行低配矩阵（4 核/2 Worker 提示）；默认 12 逻辑核下实际 DEV Worker 仍为 7–8 个。
- 未执行每样本三次真冷；每样本只有一次冷启动。
- 未执行工程切换、隔离恢复、L2 精化和属性概览 DOM 的固定路线。
- 未采集独立 GPU 呈现时间；高亮请求提交不等于屏幕呈现。

后续验收必须补齐：B1-1 冷/暖回退定位，B1-3 缓存恢复完整性，B1-4 缓存体积/写入策略，三次真冷、低配和选择 p95。未完成前不把本文件写成 `0.2.0` 全站性能通过。
