# IFC 运行时

本文件描述 IFC 文件发现、空间语义、浏览 LOD、区域近景和连接构件。GIM 语义与 IFC 的格式事实见[语义模型](../schema/semantic-model.md)，选择/高亮见[选择与交互](selection.md)。

## 1. 文件发现与坐标锚点

- IFC 文件由全局 entry resolver 从文件清单与 CBM 引用发现，不写死物理目录；`IFCFILE`/`IFC<n>` 引用与 IFCGUID 对象挂接是两种能力。
- 首个成功可用的 IFC 建立工程坐标锚点；锚点通过公开坐标读取器等待 `model.getCoordinates()` 的实际结果，不能使用 Fragments 异步查询完成前的占位单位矩阵。
- 合法单位矩阵仍被接受；工程切换后旧查询不能提交。
- 其余 IFC 按源大小排序；单个超过 64 MiB 默认排到队尾并完整加载。设置 `ifc.skipLargeFiles` 开启后跳过非关键超大文件，来源/连接线源/诊断保留。
- 缓存恢复保持持久化加载顺序，不按文件名重排。

## 2. 空间语义

- Spatial Worker 使用两遍选择性 STEP 扫描，保留空间节点、对象、placement 闭包、宿主链和关联证据。
- 空间对象关联只使用来源模型内精确 GlobalId，保留大小写和合法尾部 `$`；重复产品身份视为歧义。
- `IfcRelFillsElement` / `IfcRelVoidsElement` 保留门窗→洞口→墙的宿主链。
- 属性集、材料、类型、数量和分类按需读取；推断空间链接保留来源和置信度，不填造确定归属。
- Spatial 快照校验源、域和版本后 hydrate Map；缺失/损坏/不匹配时在全部 IFC 尝试完成后重建（版本见[缓存域](caches.md)）。
- Spatial 不替代 IFC 几何，也不覆盖变电语义缓存；读取失败不阻止已有语义/来源浏览。

## 3. 浏览 LOD（bim-lod）

生产默认 `bim-lod`：

| 级别 | 内容 | 边界 |
|---|---|---|
| LOD0 | 显式 IfcBoundingBox 或支持拉伸体的局部包围盒，保留放置方向 | 不生成开孔等 subtractive 正向代理 |
| LOD1 | IfcExtrudedAreaSolid 的矩形/闭合折线轮廓棱柱；IfcBooleanClippingResult 递归取 FirstOperand，明确省略裁剪 | 凹轮廓 earcut 封口；无法提供棱柱仍标 LOD0 |
| LOD2 | 属性面板显式请求的单对象 web-ifc 精化 | 独立 Worker 读取原 IFC，成功后替换该对象 L1 区域表示 |

- 冷转换只初始化一个 web-ifc API，打开一次派生模型；在 Worker 输入中留空 `IFCRELVOIDSELEMENT`，按类型排除机械紧固件。
- 单位从派生模型读取；坐标使用 IfcProject 长度单位、representation context、递归 LocalPlacement（含 Site 父链）和 solid/profile 放置。
- 矩阵列主序：先源放置、再单位缩放、再工程 source-to-viewer 锚点。metadata 原点只用于 Float32 精度，根矩阵抵消平移。
- 不拟合研究 benchmark 的 T；MapConversion、mapped/BRep 主体和其他未覆盖轮廓保留诊断，交给 LOD2。

## 4. 区域近景

顶部“IFC细节”在“自动（近景30m）”和“远景”之间切换，默认自动：

- 自动模式查询当前相机视锥与 30 m 范围相交的构件包围盒，包含跨区域长构件和范围内紧固件。
- 只对命中宿主分析开洞；可识别孔截面最大尺寸 ≤50 mm 时省略关系，较大或无法识别的开洞保留。
- 区域对象按原 GlobalId/ExpressId 拾取和读源属性；只有唯一 GlobalId 对应的远景对象才隐藏。
- 区域工作在各 IFC 间串行，最多驻留一个源 Worker；切换源、工程释放或空闲 30 秒后销毁。
- 区域索引/近景模板/按需属性使用独立缓存，键绑定源 SHA、条目、LOD 策略和依赖版本；损坏远景产物删除重建，源 SHA 改变拒绝近景。
- 区域子集只适用于板/杆/紧固件和已识别小孔；未缓存类型或回退路径仍可能重开整源。

## 5. 连接构件

- 连接构件按源实体类型或代理实体名称识别，先于普通 Fragments 导入提取真实三角网格；分类包含管线和接头，对象数不等于电气导线条数。
- 传输保留顶点、法线、颜色、源对象身份和放置矩阵；不由包围盒推导中心线，不改变管径。
- 每块最多 3072 个三角形（约 217 KiB，协议上限 128 对象或 4 MiB），Worker 等待主线程消费确认后继续；主线程每块让出一轮事件循环。
- 局部源对象失败记录在 `coldPipeline.connectionFailedObjects`，其余对象/普通导入继续；完整凭据不发布。
- 批次必须连续、去重且源身份一致，最终消息与完整对象数相符才算完成。
- 连接网格使用独立可选派生键 `${farKey}|near-templates-vconnection-mesh-v1|0`，不更改远景/语义/Spatial/DEV 版本。
- 端点证据来自标准 IFC 端口/连接关系或明确接线点 GUID；GL ConnectGuid 经 DEV occurrence 图核对。多义候选保留，不按距离生成已确认连接。

## 6. 选择与可见性

- IFC 拾取始终通过公开 `getVisible` 核对命中；隐藏源不参与拾取。
- 自动 L1 替换的远景对象必须隐藏，不能仅凭隔离/L2 状态判断是否需要核对。
- “仅看选中”统一限制远景、区域/L2、紧固件实例和连接线预览；多义 GlobalId 不自动选择某一对象。
- 清除选择后隔离模式保持空画面；恢复全站保留用户图层开关。
- IFC 区域运行时替换会释放旧实例，退出近景或释放时恢复其隐藏的远景对象。

## 7. 缓存与失败

| 产物 | 行为 |
|---|---|
| 远景 Fragments / bim-lod | HIT 跳过源读取/转换；损坏删除重建 |
| 区域模板 | HIT 跳过源模型与对象求值；依赖模板/放置 |
| 按需源属性 | 选择后缓存；容量/条目上限淘汰 |
| 连接网格 | 独立原子记录；暖命中在远景恢复后重放 |

- 源 SHA 改变拒绝近景求值；远端缓存不可用时回退源读取。
- IFC 转换/区域/属性失败局部化，不删除其他模型；状态区分 `allIfcReady` 与逐模型完成。
- IFC 浏览 LOD 是近似表示，不能用 `allIfcReady` 证明完整开洞几何或加工精度。
- 大 IFC 单对象精化仍需打开完整源模型；局部实验耗时不等于任意对象即时可用。
