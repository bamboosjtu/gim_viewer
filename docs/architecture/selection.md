## 选择模型

选择目标分为：

| 目标 | 含义 | 是否提升为工程整体 |
|---|---|---|
| `engineering` | 一个工程整体或待归集合 | 是 |
| `engineering-group` | “工程组成”分组 | 否，范围是该组去重后的整体 |
| `engineering-source` | 一条来源记录/上下文 | 否，保留来源身份 |
| `cbm` / `ifc-object` / `ifc-element` | 线路、设备或旧拾取路径 | 按既有规则 |

每次选择创建 `SelectionRequest`，包含请求 ID、工程会话、目标、来源（tree/search/viewport）和相机导航版本。只有最新请求可以提交属性、树选中、高亮、相机和隔离范围。旧请求的异步结果被取消或丢弃。

## 三维点击

`viewer/selection.ts` 的事件规则：

- 只有画布/视口容器的左键单击才进入拾取；右键、Ctrl/Shift/Alt、非主指针不选。
- `pointerdown` 记录起点；移动超过 **5 px** 后 `pointerup` 抑制 click。拖拽/旋转相机不触发选择。
- 相机操作只改变相机，不创建选择请求；选择也不依赖相机动作结束。
- 拾取按距离取最近命中：DEV 网格、IFC 区域对象、Fragments 远景按统一来源身份解析。
- 三维单击 **始终只选择**，不自动定位/移动相机；自动定位只服务于树/搜索等非视口来源。
- 空白处单击清除选择；隔离模式下空白处单击保持空画面和逻辑选择，不恢复全站。
- 命中未绑定/跨多个整体的粗表示时，不猜第一个；显示来源/候选提示。

## 自动定位

工具栏“自动定位：开/关”：

- 状态保存在 `localStorage` 的 `gim-auto-locate`；默认开。
- 打开时，工程树/搜索选择可在表示就绪后把相机定位到当前范围；视口点击永不自动定位。
- 相机在请求之后发生用户操作时，旧请求的自动定位被抑制。`AppState.canAutoLocate` 同时检查开关、`origin !== 'viewport'` 和相机导航版本。
- 关闭时只选择/高亮，不移动相机；用户仍可点属性面板“定位”。

变电全景按可见模型包围盒、视口宽高和视场角拟合约 80% 的视口占用，排除隐藏图层及辅助对象；不再按最大边长乘固定距离。显示策略参考标准设计（STD）声明和工程名中的电压提示，66/110/220 kV 的 far 默认 2000 m、330/500 kV 为 4000 m、750 kV 为 6000 m、1000 kV 为 10000 m。该提示只影响显示，不生成工程电压事实。透视和正交相机同步设置；电压未知或模型异常超出预设时按目标包围球兜底扩展，避免再次被裁掉。近距离框选定位按目标深度调整 near，并保留已有更宽的 far。

## 高亮

- 主效果是琥珀色轮廓（`#f59e0b`），沿网格边线绘制；仅轻微叠加颜色/自发光（约 2.5%），不覆盖原材质。
- 悬停轮廓用更浅的琥珀色、半透明；只对未选中的网格生成。
- MOD/STL 高亮克隆当前 mesh 材质后修改；共享模板材质不被改写。IFC 远景使用 Fragments 高亮，区域/L2 使用独立覆盖层。
- 高亮提交与表示替换共用短串行队列；同一选择请求在 LOD 替换后迁移，不重新读取属性、不触发几何求值。
- 高亮集合非空只证明提交完成，不证明 GPU 已呈现；下一帧是页面 RAF，不是显示器扫描。

## 隔离与恢复

- “仅看选中”按当前选择已提交的来源成员集合限制 DEV 与 IFC 各层表示；不从空间邻近补关联。
- 未加载成员保持逻辑选择；表示到达后增量高亮，不自动触发全部精细几何。
- 空选择在隔离模式中保持空画面；用户可“恢复全站”或按 Esc 清除选择并恢复。
- 分组没有可靠成员范围时不提供隔离按钮；避免把声明分组当成空范围。
- 工程切换/关闭清空隔离、基线和装饰引用。

## 来源与整体互跳

- 组成页选中整体：属性面板显示整体摘要、成员来源、关系；来源页可定位到成员。
- 来源页选中记录：属性面板显示原始字段/文件/身份；存在唯一 owner 时提供“查看所属整体”。
- 来源跨多个整体：显示候选，不自动选取第一个。
- 三维拾取先解析表示索引：唯一 owner → 整体；多 owner → 候选；单 source → 来源；无绑定 → 未关联提示。
- 搜索内部件名称可命中所属整体；来源视图仍保留该内部件记录。

## 属性面板

四个页签：概览、参数、关系、来源。

- 整体：类别、识别/组成状态、整体依据、成员数、来源状态、定位/隔离/精细模型。
- 待归集合：待确认原因、来源数量、可用表示范围。
- 分组：整体候选数、待归集合数、声明的来源文档；无成员时禁用定位/隔离。
- 单来源：原始属性分页、来源文件、详细 IFC 属性读取；不把内部参数自动汇总为整体参数。
- 参数缺失/冲突保留，不取第一个候选或相加。

## 视角历史

- 当前工程会话最多保存 20 个相机目的地/可见性快照。
- 普通相机更新按 220 ms 防抖记录；主动返回先结算待记录移动。
- 恢复成功后才消耗历史并恢复筛选；失败保留重试入口。
- 取消返回先按实际位置/目标做一次非动画定位再 `stop()`，避免 CameraControls 跳回旧目的地。
- 重复返回不并发弹栈；工程清空、选择改变和释放取消所属运动，代次守卫拒绝旧完成。

## 性能与边界

- 选择延迟受 L1 编译、表示准备、高亮提交和属性读取共同影响；不能把总时长归为单一高亮成本。
- 区域/精化切换、隐藏图层、增量连接线和工程切换的组合边界仍需原生固定路线验收。
- 触屏/手写笔、任意视角、任意点位不在当前固定路线证据内。
- 当前性能数据以开发者本地 `tmp/gim-bench/` 私有报告为准，测量方法见[Benchmark CLI](../benchmark.md)；未关闭项见[问题与限制](../open-issues.md) O-05/O-07。
