# 线路与移动端

本文件描述线路工程的运行时和 Android 边界。线路格式见[线路 MOD](../schema/powerline-mod.md)，用户行为见[桌面软件规格](../software-spec.md)与[移动端规格](../mobile-spec.md)。

## 共享核心

`packages/powerline-core/` 提供无平台依赖的线路能力：

- CBM/属性 parser core、线路图构建、路径/引用边、F2/F3/F4 投影；
- HNum 预览、领域对象与属性范围；
- 桌面和 Android 共用同一语义；平台只提供文件、SQLite、地图/渲染。

桌面通过兼容出口使用它；Android 独立 npm/SQLite，不依赖桌面 Viewer、IFC 或 Three.js。

## 桌面线路运行时

```text
GIMPKGT / 裸包
  → 解压/缓存
  → Powerline Feature（冷解析、semantic pack 或 SQLite 恢复）
  → 会话内提交线路图和 FAM/DEV 属性
  → 地图、导航和搜索投影
  → UI 挂载线路树与地图
```

- 图是可共享节点的有向图；树是展示投影，不复制节点制造新塔位。
- 线路缓存按包内路径保存唯一节点，并保留每个父节点到共享子节点的有效边。地图只生成一个共享塔标记，导航可在多个耐张段显示该塔。
- 共享档距保留一个物理身份。每个耐张段下的档距和导线行各有自己的导航键及父链。
- CBM 的已绑定引用保存实际包内路径，未解析的原文单独保存。挂点字段保留按来源上下文解析后的路径，地图和导航用同一规则查找杆塔。
- 来源面板沿 DEV、PHM 引用读取 MOD。桌面和移动端依次查找显式包内路径、所属目录中的路径和全包唯一文件名。读取和在途结果归当前工程会话所有，超过每类来源遍历上限时显示诊断。来源读取失败时保留可用分支，下次查看会重试失败的来源。
- 入库 `finish` 才提交有效 parser 标记；失败/取消的半成品不能作为合法缓存。
- 缓存恢复包不完整时重建，不用部分 graph 冒充完整工程。
- 线路打开入口位于 `features/powerline/application`。同一会话的冷解析与 semantic pack 恢复共用会话持有的解析 Worker，SQLite 恢复在图和属性均就绪后提交。冷开缓存经独立后台事务发布。
- `features/powerline/presentation` 产出地图、导航与搜索投影，UI 负责 DOM、Canvas、MapLibre 和交互。会话失效时释放地图句柄和 Worker，晚到的视图句柄只释放自身代次。
- 地图从有效 BLHA 提取经纬度/高程；导线挂点、跨越与杆塔坐标角色分开，同塔跳线不构造虚假跨塔档。导航在缺少已绑定杆塔时仅用坐标匹配唯一塔位，重合坐标保留歧义。
- MapLibre、Canvas、树和搜索共用对象选择状态；线路不显示桌面变电的选择工具栏。
- 默认 OSM 在线底图；OSM 官方瓦片异常时用 CARTO 同源栅格垫底，不整块空白。天地图为可配置能力；都不可达时 Canvas 覆盖层仍可用。
- 线路弧垂是视觉示意，不能用于净空、张力或施工放样。

## Android

| 目录或入口 | 职责 |
|---|---|
| `app/src/main.ts` | 界面和会话编排，接线地图、工程树、导入与属性面板 |
| `app/src/core/` | 项目头部解析和线路解析 Worker 接线，领域能力由 `powerline-core` 提供 |
| `app/src/native/` | Tauri 桥接和单次 SAF 导入的准备、写入及回滚 |
| `app/src/map/` | MapLibre/Canvas 底图、相机、覆盖物和地图代次 |
| `app/src/ui/` | 虚拟工程树和展示资源 |
| `app/src/plugins/` | 按插件接口装配移动端宿主 |
| `app/src-tauri/src/` | Android 原生命令、设置与私有存储 |

Android 使用独立工程和原生生命周期。冷导入与暖缓存重建复用已存来源的读取与解析，调用方分别拥有提交和回滚。原生准备分别校验已认领的来源、恢复重复工程及发布新工程。


- 只面向线路；SAF 导入、私有 SQLite、HNum 预览和领域投影独立。
- 缓存身份包含源 SHA/大小和 parser 契约；缓存不能覆盖源类型或掩盖源包替换。
- SAF 源包复制、原生准备和解压的归档上限均取自同一份[移动端配额](../../contracts/gim-limits.json)。SAF 同时检查提供方声明大小和实际复制字节。归档超限、选取取消、I/O 和源身份不一致分别返回 v1 错误码。
- SAF 每次复制写入应用私有的 `projects/.imports/<attempt>/original.gim`。原生准备只接受直接子目录中的普通文件，核对真实路径，先重命名认领，再校验大小、文件头与 SHA。丢弃与认领争用同一文件名，获认领的目录由准备方清理或提交。“我的工程”只列已完成工程。
- `.imports` 是临时交接目录，在成功、失败或取消后清理残留。进程启动且尚无新导入时，清理异常退出留下的暂存和未提交工程。目录中的文件不供重用，所以无需 LRU。此约束依赖 Android 应用私有目录和同一应用进程的所有权规则，具备同 UID 写权限或已获设备提权的主体可以绕过应用私有目录边界。
- SAF 结果与具体 Activity 和导入尝试绑定。系统文件选择导致的暂停仍保留选择，Activity 销毁或显式取消时撤销该次选择。迟到的复制仅清理自己的暂存。取消导入还需等待已启动的原生准备、缓存写入和回滚结算后释放前端导入入口，同源文件随后可重新导入。
- 取消复制会尝试中断旧任务。SAF 复制最多占用两个工作线程，新尝试可在旧提供方仍未退出时开始，两个线程都占用时立即提示稍后重试。旧任务恢复后检查取消状态并清理本次暂存。
- 打开缓存时检查私有原包登记身份、magic、大小和已观测的文件状态，再检查 SQLite 语义表完整性、版本、对象 ID 唯一性和数量。语义无效时重新投影，数据库缺失或损坏时验证源身份并有界解压重建。
- 原包身份不符时明确失败，不覆盖原包；重建完成前不替换正式数据库。
- 原生存储门禁、SAF/权限/折叠屏/沉浸模式验收见[验证](../validation.md)与[移动端规格](../mobile-spec.md)。

## 边界

- 桌面底部图依赖网络；离线 PMTiles 未实现。
- 线路三维、杆塔完整几何和设计级弧垂未实现；HNum/MOD 预览只是局部骨架。
- 桌面与移动端缓存契约独立，不能把桌面 parser 版本写入移动端。
- 线路选择/属性入口与变电三视图分离；共享底层修改必须回归线路与设备。

### 线路模型检查

Desktop 在已选对象的属性页提供三维模型入口，按可达 MOD 来源加载。完整骨架、显式选择呼高与子腿的装配、已知单桩以及线段或有外径的导体使用 SDK 中立输出。每个表示通过当前塔位和来源路径绑定。BLHA 仅定位塔位中心，缺少端点放置时弦线标记为预览。四分裂模型可以用同来源 FAM 的分裂间距核对矩阵长度单位。未解释的参数继续显示在来源页。

Android 的塔形窗口采用相同拓扑的 X/Z 投影。地图栅格回退和本地显示不要求 GNSS 或三维后端。
