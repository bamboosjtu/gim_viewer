# 设备材料清册

清册按设备、材料、构件和其他分组，再按目录类别、模型名称及名称模板列出实体。相同的层级名称可合并。名称模板用于汇总类似实例，实体行保留选中对象的实际名称。二次屏柜直接按柜子模板平级排列，主变压器保护柜等已确认功能细分显示在属性中。

每个实体有一条可选的叶子行。点击实体可查看目录分类和部件清单，原始装配和来源字段在来源视图中查看。搜索可用部件名称找到所属整体，从来源选择也能揭示其对应实体行。

分组数量按实体统计，部件不另计为设备。待归集合在导航质量提示中单列，模型树 JSON 的 `metadata.pendingWholes` 保留原因和来源 ID。来源身份、目录类别、整体边界和几何表示分别维护。

目录词汇见[实体目录](catalogs/README.md)，工程与来源视图见[三视图](composition.md)。
