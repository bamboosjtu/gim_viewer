# 清册模型树

清册目录来自 `research/实体识别/变电三维设计建模规范_索引表类.xlsx`，实际层级为：

```text
设备 / 材料 / 构件
  → 工作簿类别
    → 工作簿名称（与类别相同时合并一层）
      → 名称模板（同名时并入目录层）
        → 实体实例
          → 实际设备部件名称
            → 来源记录
```

设备及其部件分别使用设备模型索引表和设备模型部件名称对照表；材料、构件使用各自工作表。构件的梁、柱、钢梁、钢柱、钢结构等归“建筑物”，设备补保护装置；新增表格单元格标黄。未知类型、待归宿主和来源异常明确保留，不为了凑目录猜材质或归属。

清册只投影已存在的实体和成员，不生成身份或物理引用。部件只计来源成员，不重复计设备台数。每个实体只有一个可选择的实例行，每份来源只有一个来源行；实际归属恢复后，即使源 GIM 层级错误，也能在正确设备实例下按部件类型归组。紧固件等细节仍可保留其来源层次。

内部用途/边界码不决定清册目录。主变和站用用途保留在属性中；同名、同模板、树排序或目录更新都不合并实体、不修改几何根、矩阵或模板键。标准条目细分仍保留 candidate / confirmed 状态，类别确认不扩大成模型符合性判断。

生成数据和全部条目见[目录](catalogs/README.md)。

用户属性面板显示目录分类、名称、加载状态及中文部件清单，不显示实体 ID、规则版本、识别判据、边界算法和模板统计。部件名称不携带 JSON 或证据串；详细属性分页显示实际属性键值，内部证据仍供日志/导出与独立来源查询使用。
