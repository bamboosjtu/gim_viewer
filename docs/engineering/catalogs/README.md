# 实体目录

本目录唯一维护源为 [变电三维设计建模规范_索引表类.xlsx](../../../research/实体识别/变电三维设计建模规范_索引表类.xlsx)。运行时目录、分类词汇、清册分组与 gim_element 使用从同一工作簿生成的数据，不再使用旧的“设备 E01–E19 / 材料九大类 / 构件四大类”作为展示目录。

| 根分组 | 工作表 | 层级 |
|---|---|---|
| 设备 | 电气设备模型索引表 | 设备类别 → 设备名称 → 名称模板 → 实体实例 |
| 设备实例的部件 | 设备模型部件名称对照表 | 识别出的部件名称 → 实际来源，不重复计设备台数 |
| 材料 | 材料模型索引表 | 材料类别 → 材料名称 → 名称模板 → 实体实例 |
| 构件 | 构件模型索引表 | 构件类别 → 构件名称 → 名称模板 → 实体实例 |

工作簿已补充建筑物下的梁、柱、钢梁、钢柱、钢结构、门、窗、屋面、结构杆件、栏杆，保护装置归设备部件“二次屏柜柜内装置”；新增单元格标黄。普通 IFC 梁/柱/杆件不自动推断材质为钢，明确类型或名称候选另行细化。

内部工程用途/组合边界码仍用于身份及归属判断，不是第二套清册目录，也不生成物理几何。主变、站用用途不替代“变压器 → 油浸/干式”等索引层级。待归对象继续可见，名称模板只聚合展示，不合并实例身份。

更新工作簿后，在 desktop/ 执行 `npm run generate:engineering-catalog`，再执行 `npm run check:engineering-catalog`。生成命令只读取 xlsx，不读取 PDF；工具持有自己的数据副本，运行与打包不读取 Viewer。
