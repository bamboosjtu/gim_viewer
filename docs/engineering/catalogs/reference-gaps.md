# 目录参考资料的未决项

运行时 JSON 与工作簿分别维护。参考资料出现歧义时，先记录证据和规则建议，不让重生成过程自动批准映射；运行、构建、CI 和配置同步不读取工作簿。

当前工作簿的模型表包含序号、类别、中文名称、英文名称；部件表包含序号、部件名称、英文名称。实现和文档不能沿用旧工作簿的固定列位置，也不能把英文名称列当作宿主约束。部件宿主范围仍由独立 CompositionPolicy 表达。

当前参考资料需要审核的事项：

| 问题 | 位置 | 建议 |
|---|---|---|
| 消弧线圈对应 GroundTransformer、接地变压器成套装置对应 ArcExtinguishingCoil，英中文疑似对调 | 电气设备模型索引表 C26:D27 | 核对标准原文；确认两个完整模型的准确中英文对应，再分别维护条目及字段语境 |
| 控制柜、控制屏、测控柜、保护屏、保护柜、继电保护柜没有英文名称 | 电气设备模型索引表 C51:D56 | 明确它们是独立索引类型还是二次屏柜的中文别名；属于独立类型时补充唯一英文标识，不能由代码杜撰标准英文名 |
| 多种名称从合写条目拆成单行，当前共有 60/41/40 个设备/材料/构件数据行 | 三张模型表 | 数据行数与语义条目数分别核对；现有 JSON 记录 52/39/40 个模型条目，共 131 项，不能把覆盖现有 JSON 的测试解释成已审核当前工作簿全部 141 行 |
| TerminalBox、GroundResistance 同时用于完整模型和部件 | 模型表与部件表同名词 | 保留两个命名空间；补充对象角色、字段用途、宿主关系等消歧说明 |
| 两个“均压屏蔽装置”对应不同模型词条 | 材料模型索引表 | 保留两个条目和各自来源；不将中文名称的歧义映射标为唯一确认 |
| ProtectionEquipment 在部件表对应“保护设备”和“线路保护装置” | 设备模型部件名称对照表同名英文 | 明确是否同义词或英文名漏填；英文匹配保留歧义及全部来源，不静默取最后一个中文名 |
| 部件表没有可审核的宿主约束 | 设备模型部件名称对照表 | 不增加虚构列；在领域策略中列出已配置范围和未配置项，并逐项补充业务或条款依据 |

现有 JSON 的参考来源摘要和单元格位置继续绑定它所记录的参考版本，不自动改写成当前工作簿版本。上述未决项需要资料维护者确认后才能更新标准身份；算法测试和 Python 一致性测试不能代替这一审核。

真实工程人工验收仍缺少逐对象真值。开发者选择变压器、GIS、断路器的复核范围，记录固定源 SHA、来源 occurrence、期望整体、类别、部件类型、宿主和依据，再比较修改前后的拆分、合并及归属差异。未知与待归单列，不能以总实体数相近或两种实现一致作为准确率证明。
