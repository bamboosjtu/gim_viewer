# 设备目录与组合边界

**设备以施工、运维识别的整体为粒度，兼容 2018/2025 通用目录。设计拆出的本体、相单元和内部件保留为整体来源，不要求成为独立工程实体。**

下表为当前目录。编号稳定用于项目映射；版次条目仅作溯源，不能直接当工程实例类别。设备模板和实际设备实例分别记录。

### 目录版本与模型证据

- 2018 通用模型库为 18 条目 / 508 模型，裸 7z、无 CBM 和逐对象设计参数，身份主要来自根 DEV 的 `SYMBOLNAME` 与文件名；2025 为 16 条目 / 409 模型，带 CBM、FAM 设计参数和 `设备分类` 英文枚举。
- 2025 删除了支柱绝缘子、穿墙套管、二次设备、动力辅助、水工暖通、绝缘子串等旧条目，新增站用变、预制舱、SVG。因此设备词域取两版并集；只用 2025 会漏掉二次/辅助类实例，只用 2018 会漏掉新增类别。
- 目录模型数是**模板库包数**，不是工程台套数；同一根 DEV 可被多个 occurrence 引用，F4 节点数、DEV 文件数、模板数都不能当设备台数。
- 类型证据优先级为：有效设计参数/明确类别属性 → `DEV.TYPE` 枚举 → `SYMBOLNAME`/当前对象名称 → 节点名。`DEV.TYPE=OTHERS` 不自动等于未知设备；上级 F2/F3/F4 名称不覆盖当前对象角色。

## 2. 主变、中性点、端子箱

| 来源对象 | 标准角色 | 是否独立设备单元 | 工程组成表达 |
|---|---|---|---|
| 主变本体 | E01 的主体来源 | 不另建一台工程设备 | 属于主变整体；相数和本体标识在来源/参数保留 |
| 主变中性点成套装置 | E01 的组成来源 | 不另算一台主变 | 归入对应主变整体；宿主不明进入待归整体集合 |
| 散热器、油枕等 | 对应主设备的内部来源 | 否 | 不生成普通工程树节点 |
| 端子箱 | E16.terminal_box，独立设备或宿主组成 | **看情况** | 真实设备装配内不独立保留；宿主是主变、GIS 还是电容器装置不改变边界 |
| 主变基础、支架 | C-B2/C-B1 构件或组合 | 不属于设备本体 | 安装关联，不并成主变几何零件 |

“中性点装置属于主变组成”是当前口径；“它属于哪台主变”仍需实例证据。优先用明确装配/工程标识关联；名称与系统上下文只生成候选，不能按共同 F3、邻近位置、相同型号确定归属。

只交付本体时以其代表主变整体，不制造空的内部实体。多个单相本体具有相同明确主变编号及单相证据时，可组成一个工程主变整体；本体数与相别完整性另存，不把本体数当主变组数。源字段冲突或不能确定具体宿主时保留待确认状态。

## 3. 其他成套设备的边界

- GIS：明确成套/工程身份形成 E05；内部断路器、隔离开关只保留功能和来源，不另建默认工程实体。另行安装的独立断路器仍是 E06，不能将整间隔仅按名称合成一套。
- 三相设备：主变工程整体可以包含多个相本体；没有明确工程编号和成组证据时不按“三份”机械合并。
- 开关柜、预制舱：设备包含关系与独立设备身份并存。舱内各面独立柜可保留设备单元；舱级汇总与柜级汇总分别标口径，不相加成“设备总台数”。
- E04：2025 的小电阻装置是明确补充，不能沿用旧类别名称将其漏掉；具体形式作为子类保留。

## 4. 判定所需证据

先确认 occurrence，再读取有效设计参数/设备类型/型号目录映射，结合装配与独立设备角色判粒度。名称提供补充证据，不能独自判同一性；F2/F3/F4 不设置类别默认值。

跨平级来源的成套归一需要共同工程标识、带编号的工程名称及兼容装置签名；泛称“接地变”等不足以证明多份来源只对应一套。可将这些来源聚为待确认集合，避免细拆展示，也不强报套数。

分类到 E01 不代表能自动组合所有中性点装置；分类到 E05 也不证明整套边界。目录映射与组合关联分别给出 `confirmed / candidate / unresolved` 状态。

分类先使用当前对象的有效属性，名称只兜底或细化相容粗类；优先级及冲突状态见[目录总则](README.md)。屏柜、端子箱、控制柜、蓄电池组由共享 E16 子类维护；现有 protection 为项目兼容扩展，不改变 E16 主目录。

附属与独立按实际来源装配及当前对象角色共同判断：有真实设备装配边的端子箱归宿主组成，源上的独立声明不能覆盖装配边；没有装配边的独立端子箱仍建 E16 实体，不按邻近位置、共同 CBM 祖先或同名合并；预制舱内的独立设备边界保留。宿主未能确定时保持原有候选/待归，不按图上位置补归。
