# 构件目录与粒度

当前构件为 4 大类、28 子类，完整编码和名称见[机器目录索引](catalog-index.md)。构件整体可以是一樘门、一根梁、一块盖板，不要求先合成整栋建筑。

- 建筑本体 C-A1–C-A10：墙体、楼板、柱、梁、板、屋面、门、窗、楼梯栏杆、面层装修。门框/门扇、材质层等有明确组成证据时留作成员；洞口是宿主特征。
- 结构基础 C-B1–C-B7：设备支架、设备基础、建筑物基础、未分基础、型钢钢板、檩条、构架支撑。杯口/地脚/支墩指向设备基础；桩/承台/筏板/地下室底板指向建筑基础；只写基础时不硬分。
- 水工总图 C-C1–C-C5：电缆沟、排水沟、井池、围墙围栏、道路地坪。沟盖板仍归电缆沟并保留 cover/sidewall/base 角色，不为统一名称改成普通板。
- 建筑设施 C-D1–C-D6：照明、消防、安防、暖通、给排水、其他附属。灭火器/消火栓属于消防，喷淋头/管件/雨水口/集水坑/潜污泵属于给排水，成套水泵/风机/空调按 E19。爬梯/避雷针随构架支撑，标识/旗杆/宣传栏归其他附属。

具有明确对象身份的设备基础/支架不吞入电气设备。实际构件装配中不同独立构件可保留关联；同类内部拆件按角色与真实分解边归入整体。没有可靠设施身份时，不把所有沟盖板、围墙或桩身机械合成同一座设施。

IFC 材质、截面、几何内部定义不产生实体；紧固件不设置 C-DETAIL 默认实体目录，作为内部或仅来源保留。未知 Proxy/Shape 保留未知候选与原始类型、名称、来源、未知原因。
