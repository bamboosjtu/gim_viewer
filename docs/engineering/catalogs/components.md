# 构件清单

构件以施工、运维识别的构件整体为单位，沿用研究目录的构件 4 大类 25 子类。`C-A`、`C-B`、`C-C`、`C-D` 是项目映射码，不是国网标准编码；2018/2025 条目只作溯源，不写入实体类别。

构件整体不要求先恢复整栋建筑或整条设施：门、梁、盖板各自可以是整体。明确装配的内部设计拆件作为来源成员保留，不因拆件多而增加构件数。

## 目录表

| 编码 | 子类 | 目标构件整体 | 当前识别证据与边界 |
|---|---|---|---|
| C-A1 | 墙 | 一块明确墙体或墙段 | 名称 `墙`；IFC `IFCWALL`、`IFCWALLSTANDARDCASE`、`IFCCURTAINWALL`；洞口、端口为宿主特征，不建实体 |
| C-A2 | 楼板 | 一块明确楼板 | 名称 `楼板、楼面、地板`；IFC `IFCSLAB`；板内材质层是内部属性 |
| C-A3 | 柱 | 一根柱；柱段拆分保留来源段 | 名称 `柱`；IFC `IFCCOLUMN`；柱段可确认组合才合并 |
| C-A4 | 梁 | 一根梁或明确梁段 | 名称 `梁`；IFC `IFCBEAM`；梁本身可为独立构件；名称含“构架”的梁归 C-B5 |
| C-A5 | 板件 | 一块板、格栅；不含沟盖板 | 名称 `板、格栅`；IFC `IFCPLATE`；不从几何面造板；沟盖板留 C-C1 |
| C-A6 | 屋面构件 | 一个明确屋面构件或屋面组合 | 名称 `屋面、屋架、屋顶、雨棚、檐沟、采光板`；IFC `IFCROOF`；材质层不展开 |
| C-A7 | 门 | 一樘门 | 名称 `门`；IFC `IFCDOOR`；门扇、门框为已暴露组件；厂区“大门”先落 C-C4 |
| C-A8 | 窗 | 一樘窗 | 名称 `窗、百叶`；IFC `IFCWINDOW`；玻璃、框料不从内部类型拆出 |
| C-A9 | 楼梯与栏杆 | 一部/跑楼梯或一段栏杆 | 名称 `楼梯、梯段、栏杆、扶手、台阶`；IFC `IFCSTAIR`、`IFCSTAIRFLIGHT`、`IFCRAILING`；踏步分级为内部 |
| C-A10 | 建筑面层 | 一块明确交付的面层构件 | 名称 `面层、垫层、涂料、饰面、吊顶`；IFC `IFCCOVERING`；仅材质层不造实体 |
| C-B1 | 设备支架 | 一套支架或一件支架构件 | 名称 `支架、支墩、设备底座`；DEV `equipmentsupportandfoundation`；柱身、底板为组件；父级为 E 类时独立关联 |
| C-B2 | 基础 | 一座基础或已暴露基础构件 | 名称 `基础、承台、钢桩、杯口`；IFC `IFCFOOTING`、`IFCPILE`；明确基础独立于设备；支架与基础一体时只有一个构件，不复制出第二个实例 |
| C-B3 | 型钢与钢板 | 一根杆件或一块钢板 | 名称 `型钢、角钢、槽钢、工字钢、钢板`，以及截面前缀 `PD/PL/PIP/L/C/H/I` 加数字；IFC `IFCMEMBER`；截面定义是内部组成；扁钢、圆钢先落 M06 |
| C-B4 | 檩条 | 一根檩条 | 名称 `檩条` |
| C-B5 | 构架与桁架 | 一榀/套构架，或构架梁、柱、支撑 | 名称 `构架、龙门架、桁架、网架、系杆、剪刀撑`；不按名称造齐构架 |
| C-C1 | 电缆沟构件 | 一段明确沟设施或构件 | 名称 `电缆沟、电缆隧道、沟盖板、沟壁、沟底、竖井支架`；角色写入 `interpretation.role`，见下节；与 C-A5、E17 分界 |
| C-C2 | 排水沟构件 | 一段明确沟设施或构件 | 名称 `排水沟、雨水沟、截水沟、排水明沟、边沟`；转角件保留身份，不并与直段 |
| C-C3 | 井池构件 | 一座井/池，或外露井壁、井盖 | 名称 `检查井、雨水井、阀门井、手孔井、化粪池、事故油池、井壁、井盖` |
| C-C4 | 围墙与围栏构件 | 一段/单元设施，含其墙柱、墙身、地梁 | 名称 `围墙、围栏、护栏、栅栏、大门`；DEV `metalfence`；单段/单元为整体；无“围墙/围栏”字样的墙身按 C-A1、地梁按 C-A4 |
| C-C5 | 道路与地坪构件 | 一块/段道路、地坪构件 | 名称 `道路、路面、地坪、散水`；内部铺装层不拆 |
| C-D1 | 照明设施 | 一套/盏器具 | 名称 `灯具、指示灯、投光灯、吸顶灯、格栅灯、照明灯、路灯、疏散指示、安全出口`；DEV `lampsandlanterns`、IFC `IFCLIGHTFIXTURE`；端子板为组件 |
| C-D2 | 消防报警设施 | 一个独立探测/报警器具 | 名称 `探测器、声光报警、手动报警、报警按钮`；`报警按钮` 先按独立功能头词命中 C-D2，不再被 `part` 的“按钮”抢先 |
| C-D3 | 视频与门禁设施 | 一台摄像机等安防器具 | 名称 `摄像、球机、门禁`；2018 摄像头条目保留为来源 |
| C-D4 | 暖通给排水管件 | 一段管、一个管件或末端 | 名称 `钢管、管道、弯头、三通、喷头、镀锌管、排水管`；IFC `IFCFLOWSEGMENT`、`IFCFLOWFITTING`、`IFCPIPESEGMENT`、`IFCPIPEFITTING`、`IFCDUCTSEGMENT`、`IFCDUCTFITTING` |
| C-D5 | 其他附属设施 | 一个明确设施构件 | 名称 `爬梯、避雷针、铭牌、标识`；避雷器归 E15，不是此子类 |

## 与其他目录的边界

| 相邻对象 | 分界 |
|---|---|
| 设备 vs 构件 | 设备按台/套/面计（E*）；构件按构件整体计（C*）；设备支架、基础属构件 |
| 材料 vs 构件 | 导线、母线、金具、绝缘子、电缆、接地材料、套管槽盒属 M*；支架、沟、井、道路属 C* |
| 构件 vs 内部设计件 | 门扇/门框、窗玻璃、楼梯踏步、支架柱身/底板、沟压顶是内部来源；整体不因内部层数增加 |
| 构件 vs 设备基础 | 基础是独立构件实体，与设备 `associated_with`，不并入设备几何零件 |
| 构件 vs U-OBJECT | 无法证明构件类别时保留 `U-OBJECT`，不按形状、位置或父级名称猜类别 |

## 独立构件：门、梁、盖板

- 门按 C-A7，厂区“大门”先命中 C-C4；“门”这一关键词不做构造类型细分。
- 梁按 C-A4 独立成整体；构架梁、系杆、剪刀撑按 C-B5，不并入单根梁。
- 沟盖板按 C-C1 的 `cover` 角色保留；其他独立盖板没有“沟盖板”字样时按 C-A5 板件判类。当前规则不为了目录整齐把所有盖板改成 C-A5。

## 组合与待归集合

| 情形 | 处理 |
|---|---|
| 只交付墙身、墙柱、地梁 | 按名称保留为 C-A1、C-A4 构件；部件或拆件身份且无宿主时进待归集合，不强行归整段围墙 |
| 平级拆件缺工程身份 | 待归集合，`peer_fragment_engineering_identity_insufficient` |
| 部件型来源找不到宿主 | 待归集合，`component_whole_unresolved` |
| 成套来源缺少带编号名称 | 待归集合，`unnumbered_set_identity_requires_confirmation` |
| 同名同码出现多个签名 | 诊断 `assembly_identity_collision`，不合并 |

不追求少节点把所有围墙或沟盖板合成一个对象，也不把内部设计层数当构件数量。

## C-C1 的角色口径

电缆沟整体默认保留角色成员，不把盖板一律改判 C-A5。角色不再只靠成员名称/父子关系隐含表达，而是写入 `ObjectInterpretation.role`（`catalogRules.json` 的 `c1Roles`）：

| 角色 | 典型来源 | 处理 |
|---|---|---|
| `cover` | 沟盖板、压顶 | 作为沟的成员；名称保留“沟盖板”时单独交付仍归 C-C1 |
| `sidewall` | 沟壁、侧墙 | 成段沟以段为整体，侧壁不另立设施 |
| `base` | 沟底、垫层 | 作为内部来源，不展开设计层 |
| 其他 | 竖井支架、转角件 | 保留来源身份，不合并成一段 |

当前 [catalogRules.json](../../../desktop/src/engineering/catalogRules.json) 没有 role 枚举字段：`cover/sidewall/base` 是研究口径的角色词，v0.2 通过成员名称与父子关系表达，不生成新编码。

## C-D4 与 E19 的分工

| 对象 | 归属 | 依据 |
|---|---|---|
| 管段、管件、末端（钢管、管道、弯头、三通、喷头、镀锌管、排水管） | C-D4 | 名称规则；`IFCFLOW*`、`IFCPIPE*`、`IFCDUCT*` 类型 |
| 独立风机、水泵、空调、消防栓、灭火器、除湿机、闸阀 | E19 | 名称规则；`IFCFAN`、`IFCPUMP`、`IFCVALVE` |
| 名称同时含两类词（如“空调管道”） | E19 | 目录按数组顺序先命中 E19；如需改判，应调整规则顺序而不是就地改类别 |

## 保留待识别

- 25 子类不含 `C-DETAIL`：IFC 紧固件只产生 `detail` 标记，没有面向默认工程实体的紧固件分支；名称含“螺栓”而无类型标记时类别落 `U-OBJECT`（有宿主时为成员）。
- “火灾报警控制器”“消防主机”等名称未命中 C-D2，落 `U-OBJECT`，不按父级或位置强归。
- 无“围墙/围栏”字样、又无设施身份证据的墙柱、墙身按 C-A1，地梁按 C-A4；压顶等未覆盖表述落 `U-OBJECT`。
- 名称与 IFC 类型冲突时按名称建实体并记录 `conflict`（如名称“构架”、类型 `IFCMEMBER` 归 C-B5，冲突为 `C-B3!=C-B5`）。
