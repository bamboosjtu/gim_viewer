# 装置性材料

当前 M01–M09 的编码和名称见[机器目录索引](catalog-index.md)。默认粒度、子类与证据由实体层确定，清册只投影，不为了少节点合并材料。

| 类别 | 子类及边界 |
|---|---|
| 导线、母线、电缆 | 明确的一段，保留本体；不按线股/顶点拆分，不按接触合并。柜内母排可作为柜的组成。 |
| 金具 | 防护金具、线夹、引流板、连接金具、母线金具；组合内部紧固件不另计。均压环/屏蔽环不能被“绝缘子”定语吞掉。 |
| 绝缘子 | 支柱、串、散装、本体待细分；类型中的支柱/串属性优先。串内金具球和盘片不与整串同级累加。 |
| 接地材料 | 扁钢/圆钢、接地极/引下线，未知形式保留待细分；没有明确组成不造接地网整体。 |
| 套管 | 穿墙、预埋、母线、本体待细分；主变/断路器独立交付的本体套管可保留材料并注明宿主待归，不假定为穿墙套管。 |
| 槽盒 | 电缆桥架、电缆槽盒、本体待细分；盖板/隔板属于明确装配内组成。电缆、槽盒、土建电缆沟分别计口径。 |
| 其他材料 | 封堵与抱箍、未细分材料。必须保留可读子类和未知原因，不能把未知任意对象塞进材料。 |

电缆终端属于 E17；母线/绝缘子支架属于 C-B1，基础按设备/建筑/未分三类；材质、截面定义不产生材料 occurrence。每个实际 occurrence 保留独立身份，缺少实物边界的内部件进入所属整体或待归集合。

对象数、来源数和长度/重量/供货数量不是同一量。已交付尺寸和工程量保留原始字段及单位，从来源查看；清册不按来源数补造 1 m、1 kg 或供货数量，不擅自汇总冲突量。

## 跨目录边界

| 容易混淆 | 采用口径 |
|---|---|
| 绝缘子 vs 绝缘子支架/基础 | 绝缘子归 M04；支架/基础归 C-B1/C-B2，按中心对象与属性判定。 |
| 母线 vs 母线支架 | 母线归 M02；支架归 C-B1，不先命中“母线”就结束。 |
| 电缆 vs 电缆沟/终端/槽盒 | 电缆 M05；土建沟 C-C1；独立安装的电缆终端 E17；槽盒/桥架 M08。 |
| 套管 vs 设备本体套管 | 穿墙/预埋/母线套管按 M07；主变/断路器引线套管独立成件时暂按 M07“本体”并标宿主待归，不并入穿墙套管子类。 |
| 设备基础 vs 建筑基础 | 杯口/地脚/支墩/设备基础 C-B2；桩/承台/筏板/条形/地下室底板 C-B3；只有“基础”且无归属时 C-B4。 |
| 消防 vs 给排水 | 灭火装置/消火栓/灭火器箱/探测报警 C-D2；喷淋头/水管/雨水口/集水坑/潜污泵 C-D5；成套消防泵 E19。 |
| 爬梯/避雷针 vs 其他附属 | 检修爬梯/钢梯/避雷针/避雷带随构架支撑 C-B7；标识/旗杆/宣传栏 C-D6。 |
| IFC 材质/截面 vs 材料件 | 内部属性，不产生材料 occurrence；紧固件不设默认实体，归宿主或仅来源。 |
