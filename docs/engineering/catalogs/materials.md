# 装置性材料目录

装置性材料以实际安装、识别和选择的整体为单位，沿用研究目录的材料 7 大类口径。`M01`–`M07` 是项目映射码，不是国网标准编码；2018/2025 条目只作溯源，不写入实体类别。

材料整体分“段”和“件”两种粒度，不按顶点、线股、盘片或设计拆件继续细分。设计内部件作为来源成员保留，不默认建立工程实体。

## 目录表

| 编码 | 大类/子类 | 目标粒度 | 当前识别证据 | 边界 |
|---|---|---|---|---|
| M01 | 导线：本体 | 一段明确导线（`segment`） | 名称 `导线、软导体、硬导体、地线`；DEV `flexiblecircuitconductor` | 不按顶点、线股拆件；地线按导线计，不归 M06 |
| M02 | 母线：本体 | 一段明确母线（`segment`） | 名称 `母线、母排、管母、排母`；DEV `tubularbus`、`rectangularbus` | 柜内母排可作为 E09 组成；“母线支架”落 C-B1、“母线设备柜”落 E09 |
| M03 | 金具：防护金具、线夹、连接金具、引流板、母线金具 | 一个金具件或明确组合件（`item`） | 名称 `间隔棒、线夹、金具、引流板、联板、挂环、挂板、调整板、球头、碗头、防振锤`；DEV `tensionclamp`、`equipmentcableclamp`、`tconnectionfittings`、`bussupportfixed` | 组合内螺母、销不另立同级金具；紧固件只作 `detail`；`bussupportfixed` 名称含“支架”时按名称落 C-B1 并记类型冲突 |
| M04 | 绝缘子：绝缘子串、支柱绝缘子、散装、本体待细分 | 一串明确组合或一个独立件（`item`） | 名称 `绝缘子`；DEV `chaininsulation`、`postinsulator`、`insulatorssring`、`acpillarinsulator` | 盘片不与整串同级累加；2018 `11 支柱绝缘子` 在此兼容；绝缘子支架、基础归 C-B1、C-B2 |
| M05 | 电缆：本体 | 一段明确电缆（`segment`） | 名称 `电缆` | 电缆终端 E17、电缆沟 C-C1、槽盒 M07；不因同沟、同型号合并多段 |
| M06 | 接地材料：扁钢/圆钢、接地极/引下线 | 线状材料按段，接地极按件 | 名称 `接地网、接地极、引下线、扁钢、圆钢` | 有明确组成才建接地网组合；扁钢、圆钢先落 M06，不落 C-B3；接地箱 E17、接地开关 E08 |
| M07 | 其他材料：套管、槽盒、未细分材料（标签“套管与槽盒”） | 按明确件或段 | 名称 `套管、槽盒`；DEV `walltubeinsulator`、`acwallbushing`；IFC `IFCCABLECARRIERSEGMENT` | 2018 `13 穿墙套管` 在此兼容；槽盒不与电缆混同；未细分材料按研究口径保留可读子类与未知原因（当前无独立编码） |

## 段与件的口径

| 口径 | 适用 | 边界 |
|---|---|---|
| 段（`segment`） | M01、M02、M05，以及 M06 的线状部分 | 以一段可独立安装、识别、选择的连续体为单位；端点、走向、长度是属性而非新对象 |
| 件（`item`） | M03、M04 的独立件与整串、M06 的接地极、M07 | 一个安装件或一串为单位；组合内部零件为来源成员 |
| 组合 | M03 明确组合件、M04 绝缘子串、M06 接地网 | 需要明确装配或成套证据；共同型号、邻近位置、共同父节点不单独成立 |
| 复用实例 | 全部 | 同一模板的多次实例分别计数，不因几何相同合并 |

段的首尾接触、同材质、同型号不足以把多个 occurrence 合成一件材料；只有明确装配或成套身份才建立组合整体。

## 材料何时成为整体成员

材料不会仅因类别为 `M*` 就脱离父整体：父级缺失或父级为 `U-OBJECT` 时才独立成整体，其余情况随宿主成为成员。

| 情形 | 处理 |
|---|---|
| 柜内母排、主变内部引线、设备内部电缆 | 作为所属整体的成员，保留材料类别，不另建实体 |
| 绝缘子串内金具球、线夹螺栓 | 作为串或金具的成员，不另立同级金具 |
| 材料父级缺失或为 `U-OBJECT` | 独立成整体，必要时与已知宿主 `associated_with` |
| 同一材料被多个整体引用 | 按来源 occurrence 分别计数，不复用台数 |

成员关系不改变材料类别：快照中仍记 `M0x`，只在整体统计时按整体归并。

## 工程量与缺省值

| 记录项 | 规则 |
|---|---|
| 对象个数 | 按整体计数；来源记录数、内部件数、材料整体数分别统计 |
| 尺寸、长度、重量、供货数量 | 只记录来源有证据的值；缺失即未知 |
| 缺省填充 | 不自动填 `1 m`、`1 kg`；数字 `1` 只表示真实计数 1 段/件 |
| 汇总 | 个数与工程量分别汇总，不用缺省值凑总量 |
| 当前实现 | 目录与快照不含计量字段，工程量留在来源属性与属性面板 |

模型精度差异不改变上述规则：粗模型不补造内部件，细模型不因拆件多而增加材料整体数。

## 材料类型、名称与独立功能

| 顺序 | 证据 | 结果 |
|---|---|---|
| 1 | 独立功能头词（`independent` 表） | 覆盖材料类型与名称，如端子箱仍为 `E16.terminal_box`、配电箱仍为 E17 |
| 2 | 材料类型属性（DEV 类型别名属 `M*` 且 `traits.materialType`） | 覆盖名称，`basis: material_type` |
| 3 | 对象自身名称按目录顺序 | 首个命中，`basis: object_name` |
| 4 | 类型别名（DEV `source_type`、IFC 类型） | 仅名称未命中时兜底，`basis: type` |
| 5 | 家族身份候选（设备名称、工程中名称） | 名称仍未知时尝试，`basis: family_identity_candidate` |

IFC 的材质、截面、材质层和构造层是内部属性，不据此建立材料实体；只有外露且可独立安装识别的对象才进入本目录。

## 必须统一的边界

| 容易混淆 | 采用口径 |
|---|---|
| 绝缘子 vs 绝缘子支架、基础 | M04 vs C-B1、C-B2；按中心对象与属性判定，名称含“支架”先落 C-B1 |
| 母线 vs 母线支架 vs 母线设备柜 | M02 vs C-B1 vs E09；不先命中“母线”就结束 |
| 电缆 vs 电缆沟、终端、槽盒 | M05 vs C-C1 / E17 / M07；同一路径上的三个对象分属三处 |
| 金具 vs 紧固件 | 金具按安装件整体识别；紧固件只作 `detail`，不因 IFC 单独暴露新建实体 |
| 段 vs 多段 | 一段一个整体；同型号、同路径不合并 |
| 材料类型属性 vs 名称 | 材料类型优先于名称；独立头词最高；类型别名只在名称未命中时兜底 |

## 2018 条目溯源

| 2018 条目 | 落点 | 说明 |
|---|---|---|
| `11 支柱绝缘子` | M04 | 按绝缘子整体判类，不因“支柱”改判构件 |
| `13 穿墙套管` | M07 | 穿墙套管是材料件，不是 C-A1 墙体构件 |
| 绝缘子串、金具条目 | M04、M03 | 串按整体，金具按件 |
| 2025 无对应旧条目 | 保留对象 | 旧对象不因新版无条目而删除 |

两版条目只用于溯源与评审对照；`entity.category` 始终写项目映射码。

## 保留待识别

- 仅靠名称无法识别的材料表述（如“桥架”）落 `U-OBJECT`；有 IFC `IFCCABLECARRIERSEGMENT` 类型时按 M07 判类。
- M07 的“未细分材料”没有独立子类编码：名称不含 `套管、槽盒` 时落 `U-OBJECT`，不能当作无信息兜底。
- “散装”“本体待细分”保留研究口径，不据名称强猜具体形式或型号。
- 只有材质层、图示填充或剖面定义的对象不建材料实体，保留为宿主属性。
