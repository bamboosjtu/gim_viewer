# 桌面软件规格

GIM Viewer 是面向电网工程模型的本地浏览器，当前运行于 Tauri 2 桌面应用。
变电工程提供层级、属性和三维浏览；线路工程提供工程地图、对象关系和来源核验。
工程解析与缓存位于本地；在线底图需要网络服务。

## 输入与打开

用户选择 `.gim` 文件。应用根据源文件头识别变电或线路工程，计算 SHA-256，校验本地缓存。
合法缓存恢复当前工程；缓存缺失或无效时，解压并解析源包。桌面优先使用原生解压，
浏览器开发模式可使用 WASM 路径。损坏包、无法定位压缩载荷、资源配额或根引用异常应反馈错误。

打开另一工程时取消前一工程任务并释放其资源。旧请求不能向新工程提交场景、属性或缓存结果。
局部文件缺失和不支持的图元需要保留诊断，不能据此让其他可用对象消失。

缓存只加速读取，不改变源文件。源身份和各缓存域的校验规则见 [架构](architecture.md)。
缓存命中不保证全部模型立即可见，IFC 加载和 DEV 几何提交仍有独立进度。

## 共同交互

- 工程树按源层级展示对象，搜索可定位节点并触发相同的选择流程。
- 属性抽屉展示当前对象的分组属性、关联对象和来源信息，支持 CSV 导出。
- 当前选择控制属性、高亮和相机/地图定位；异步返回以最新选择的提交权为准。
- 来源信息保留原字段和文件关联，空值、未关联及歧义不伪装为确定事实。
- 诊断导出提供工程、加载状态、性能时序与局部几何信息。

## 变电工程

### 层级与属性

CBM 提供工程骨架。F1/F2/F3/F4 与 PARTINDEX 等节点保留原始字段和可读名称；
FAM 原始行、内部键、标签、值及来源独立保存。重复键的单值显示视图与完整来源记录并存。
系统分类代码和业务编码作为来源证据，不强行映射成统一专业或唯一业务身份。

PARTINDEX 是语义身份别名。它关联所属物理装配子树中的 DEV occurrence，
自身不重复生成一套几何。候选不唯一时保留歧义，选中部件不能扩大到其他装配根。

### 三维加载

应用自动发现并尝试加载工程 IFC。发现依据 CBM 引用及全局条目解析，物理目录位置不限于 DEV。
IFC 文件可加载不代表每个 CBM 都具有 IFCGUID 对象关联。
首个 IFC 参与建立坐标锚点，缓存恢复保持源加载顺序。

DEV/PHM/MOD/STL 管线后台渐进生成、缓存并显示设备几何。共享 DEV 模板可以产生多个独立装配实例；
递归 PHM 保留逐边矩阵、颜色与装配路径。部分 primitive 支持近似显示，部分只解析或保留来源。
能力边界见 [XML MOD](schema/substation-mod.md)。同 UUID 的 GL 文件为可选辅助来源。

属性中可显示几何状态和冷/暖来源。`empty`、`unsupported`、`partial` 与运行失败具有不同含义；
完整加载阶段完成也不意味着所有源图元都已渲染。

三维视图支持选择、高亮和定位。空间语义索引提供 IFC 空间节点、对象和来源关联；
属性集、数量、材料等详细内容按需读取。推断链接保留证据强度。

### 单线图

存在 SCH/STD/SLD 时加载逻辑模型和单线图；缺失时三维与属性功能继续可用。
STD 为 SVG 内容时不生成 STD 电气层级。单线图通过净化后的 SVG 图像呈现，
具有有效关联的 gridId 可参与选择联动；不能宣称任意对象都能一一关联。
格式与内容分型见 [逻辑模型](schema/logical-model.md)。

## 线路工程

### 地图与联动

地图显示有效塔位、导线/地线关系和跨越对象，树与地图可双向定位选择。
塔位以 CBM 的 BLHA 等来源字段建立，POINT_LINE MOD 中的点是其局部对象的点，
不能全部计为杆塔。边界共享节点按来源路径复用，引用关系保留。

地图工作区是二维工程地图。杆塔 HNum/MOD 可在来源视图提供局部骨架预览，
这不等于完整线路或杆塔三维模型。没有可预览数据时应安全降级。

属性按概览、参数、关系和来源组织，支持工程内搜索、地图截图与 CSV 输出。
原线路长度、几何测量长度、回路数量、导线数量各有独立口径，不能相互替代。

### 底图

当前默认采用 OSM 在线底图；配置天地图 Key 后可使用对应底图，服务异常时回退 OSM 或 Canvas。
Canvas 保留工程覆盖层的基本交互，不提供地理影像。
在仓库根 `.env` 配置 `VITE_TIANDITU_KEY`，启动或构建时读取；不要提交真实 Key。
底图使用保留服务署名，不进行后台批量下载或离线打包。

### 弧垂

当前导线曲线是二维视觉示意，使用采样近似及缺省值，不能用于工程净空、张力或施工放样。
`KVALUE`、挂点和 `MATRIX0` 来源可供审计，不能把现有示意算法宣称为已核验的设计悬链线公式。
四类线路 MOD 与字段边界见 [线路 MOD](schema/powerline-mod.md)。

## 能力限制

本文件描述桌面端；Android 线路应用的当前实现与验收边界见 [移动端规格](mobile-spec.md)。
外部业务插件、坐标核验闭环和独立线路三维仍未实现。
PMTiles 开关处于关闭状态。Fragments 缓存默认关闭，调试开关不等于产品默认能力。
这些限制对应的开发与核验事项统一见 [未决事项](open-issues.md)。

当前正确性证据范围见 [验证](validation.md)，性能声明必须符合 [性能](performance.md) 的测量口径。
