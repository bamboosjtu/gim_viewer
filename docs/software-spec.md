# 桌面软件规格

GIM Viewer 是面向电网工程模型的本地浏览器，当前运行于 Tauri 2 桌面应用，桌面版本 0.1.3。变电工程提供层级、属性和三维浏览；线路工程提供工程地图、对象关系和来源核验；独立设备模型提供装配层级、属性与三维浏览。工程解析与缓存位于本地；在线底图需要网络服务。

## 输入与打开

用户选择 `.gim` 文件。应用根据源文件头及实际入口结构识别变电、线路或独立设备，计算 SHA-256，校验本地缓存。GIMPKGS 头也可承载设备；无自定义头的设备归档须经内容校验，不能仅凭压缩签名认定类型。合法缓存恢复当前工程；缓存缺失或无效时，解压并解析源包。桌面优先使用原生解压，浏览器开发模式可使用 WASM 路径。损坏包、无法定位压缩载荷、资源配额或根引用异常应反馈错误。

打开另一工程时取消前一工程任务并释放其资源。旧请求不能向新工程提交场景、属性或缓存结果。 局部文件缺失和不支持的图元需要保留诊断，不能据此让其他可用对象消失。

缓存只加速读取，不改变源文件。源身份和各缓存域的校验规则见 [架构](architecture.md)。 缓存命中不保证全部模型立即可见，IFC 加载和 DEV 几何提交仍有独立进度。

## 共同交互

独立设备以唯一 `ENTITYNAME=Device` CBM 为入口；无 CBM 的包可使用唯一、全部 DEV 可达且无环的 DEV 装配根，并须有实际几何引用。多根、断引用或环形装配不任意选取入口。展示根设备及递归子装配，保留原始 DEV/FAM 名称、参数和来源，不伪造原始 ENTITYNAME 或 CBM 文件。无需补造 F1–F4 工程节点或 IFC；设备自动显示、可搜索定位并通过现有属性面板请求精细模型。设备语义文本兼容 UTF-8 与 GBK，物理源文件不改写。设备来源提取与各 LOD 派生缓存可复用，打开时重新建立小型设备树；不将其冒充完整变电语义缓存命中。保留工程层级的包继续按工程结构浏览，没有 IFC 时仍可自动显示可达 DEV 几何。

- 线路工程树按源层级展示对象；变电工程默认使用业务树，可切换来源和 IFC 空间视图，保留原始 CBM 节点、IFC 对象及来源路径引用。三个视图共用搜索、选择、高亮和属性抽屉，搜索结果可选中、高亮并定位对象。开发中的投影规则、证据和边界见[业务树](impl/model-tree-business.md)、[来源](impl/model-tree-source.md)和[空间](impl/model-tree-spatial.md)。
- 属性抽屉默认折叠，选择对象时按“自动展开属性”设置决定是否打开；折叠后三维/地图视口占用释放出的宽度。
- 顶栏只保留“打开 GIM / 关闭工程 / 更多”。附加 IFC、缓存管理、IFC 细节、启动恢复上次工程、自动展开属性位于“更多”菜单；IFC 细节不再作为普通浏览的主按钮，点击后打开说明型设置面板。
- 空态显示工程骨架占位、打开按钮、继续上次工程和最近工程列表；打开期间切换为骨架，不再同时显示“尚未打开工程”；底部加载卡显示阶段进度条、当前阶段和已用秒数，首个 IFC 可用后隐藏。
- 首个可用 IFC 后隐藏中央 loading，底部状态栏持续显示 IFC 当前文件/来源和 DEV 实例/LOD 进度；后台 IFC 不再重新覆盖画布。普通选择反馈写入选择状态，不重新开启工程加载浮层；取消、精化与跨工程状态已在原生 Release 复核，见[验证 §4](validation.md#4-真实桌面复核)。
- 剩余 IFC 按源大小排序；单个超过 64 MB 的 IFC 默认仍排到队尾并标注，避免小模型陪它长时间停在“x/y”。设置面板可开启“跳过 >64 MB 非关键 IFC”（默认关闭）：开启后超过 64 MiB 的非关键 IFC 不转换，状态栏追加“已跳过 N 个超大 IFC”，来源、连接线源和诊断仍保留，不静默丢弃；未开启时不跳过。
- 状态栏显示索引发布状态：核心索引提交后提示“暖启动已就绪 · 属性补写中”，第二阶段完成后显示“索引已发布”，失败保留“索引发布未完成”并在悬停中给出原因。
- 属性抽屉首屏为设备摘要（名称、类型 · 电压等级 · 所属系统路径）与不超过 8 行的关键参数（名称/电压/厂家/型号/额定参数/期次，空值与占位符不占行），工程标识默认折叠；全部原始字段仍保留在“参数/来源”页签并可搜索，技术字段默认折叠。
- 属性粒度与设备一致：设备下组件（PARTINDEX / DEV_SUBDEVICE）的 FAM/DEV 属性按设备合并，设备自身的值优先、组件值只补缺，摘要注明合并来源数；设备可能位于 F0–F4 任意层级，合并按树结构而非固定层级。
- 属性抽屉展示当前对象的分组属性、关联对象和来源信息，支持 CSV 导出。
- 当前选择控制属性、高亮和相机/地图定位；异步返回以最新选择的提交权为准。
- 来源信息保留原字段和文件关联，空值、未关联及歧义不伪装为确定事实。
- 诊断导出提供工程、加载状态、性能时序与局部几何信息。

变电工程打开时默认整站远景全景：不恢复上次相机位置，只恢复层级树展开状态；用户手动操作相机或选中对象后，本次会话不再自动调整视角。若场景包含覆盖站址的场地大平面，全景取景剔除这类离群网格，避免相机被推到站址外。启动时自动恢复上次工程为可关闭选项，默认关闭。最近工程路径只能由数据库记录授权，页面不能提交任意本地路径。缓存管理以卡片展示每个工程的类型、版本、大小、更新时间与路径，提供逐工程“校验缓存/打开工程/复制诊断/复制摘要/删除”；校验结果显示有效或 miss reason，不自动重建。

## 变电工程

### 层级与属性

CBM 提供工程骨架。F1/F2/F3/F4 与 PARTINDEX 等节点保留原始字段和可读名称；FAM 原始行、内部键、标签、值及来源独立保存。重复键的单值显示视图与完整来源记录并存。系统分类代码和业务编码作为来源证据，不强行映射成统一专业或唯一业务身份。

PARTINDEX 是语义身份别名。它关联所属物理装配子树中的 DEV occurrence，自身不重复生成一套几何。候选不唯一时保留歧义，选中部件不能扩大到其他装配根。

### 导航视图

变电工程默认展示“业务树”，按安装工程和建筑工程组织来源对象，保留原 CBM 来源层级和 IFC 空间入口。模式条提供业务树、来源和空间三个视图；来源视图显示原始 CBM 层级，空间视图只使用有效 IFC 空间包含关系，空间关系不足时降级到既有功能系统视图。首次打开先提供明确 CBM 归属，FAM 语义发布、IFC 来源与基础几何结算后在后台补充完整业务投影并原子保存；完整业务树不作为首个可用几何或当前视图的等待条件。合法暖缓存只加载、校验并绑定来源节点，不重新分类或启动业务 Worker；快照缺失、损坏或契约变化时仅重建业务投影。所有视图保留来源身份，不改变物理几何种子。实现与验证边界见[业务树](impl/model-tree-business.md)、[来源](impl/model-tree-source.md)和[空间](impl/model-tree-spatial.md)。

模式条显示空间关联覆盖率，该百分比只表示命中 IFC 空间的 CBM 节点比例，未落位对象仍保留在质量分组中。空间投影按站区、建筑、楼层与空间组织构件，单次展开最多生成固定行数，其余对象通过“加载更多”继续生成，不能静默丢失。未落入容器、未关联、原点矩阵或网格放置的对象进入独立质量分组，分组与覆盖率计数来自空间索引而非推断。

节点第一次展开时才生成子行，大对象分支使用虚拟窗口；投影输入未变化时复用索引，刷新保留展开、搜索及滚动状态。搜索覆盖区域、功能单元、设备、IFC 对象及来源别名，命中后展开祖先链并显露目标行。独立设备继续使用原装配/功能系统树。

### 三维加载

应用自动发现并尝试加载工程 IFC。发现依据 CBM 引用及全局条目解析，物理目录位置不限于 DEV。IFC 文件可加载不代表每个 CBM 都具有 IFCGUID 对象关联。首个 IFC 参与建立坐标锚点，缓存恢复保持源加载顺序。

IFC 默认先显示省略关系开洞及紧固件的远景表示。“IFC细节：自动（近景30m）”按当前视域恢复区域内的构件和紧固件，省略可识别的 ≤50mm 小孔，较大及无法识别的开洞保留；可即时切换到“远景”。源文件和对象身份保持，派生缓存用于重复打开。该表示服务于 BIM 浏览，不能用于检修孔阵、加工或精确几何量测；首次进入未缓存区域仍需打开完整源模型。

完整远景转换及区域索引复用同一次完整 IFC 解析。支持的较大连接来源可额外提取一个有界首对象子集，先提供第一份表示，再继续完整源转换；不保证任意大源立即显示。连接构件使用真实源网格增量呈现，状态与设备基础表示分别报告；分类也包含管线和接头，对象数不是电气导线条数。暖恢复可直接使用正式远景中的连接表示，不要求额外保留一份大型预览副本。

基础属性随远景表示加载；属性集、类型与材料在选择对象后从原始 IFC 按需读取并缓存。读取期间显示基础信息和加载状态，失败时保留来源并反馈原因。连接对象面板分别说明 CBM 来源、DEV 装配及设备端点；支持的 IFC 端口/连接关系及明确接线点 GUID 引用可用于核对设备实例，多义引用显示候选并保留未归属。没有收集端点元数据的旧缓存与已扫描但没有引用的来源分别说明，不能按距离补造已确认连接。

DEV/PHM/MOD/STL 管线自动生成、缓存并显示设备，不需要点击工程树才能出现。普通浏览采用 L0/L1，远景和视野外保留低成本的实际主体轮廓，可见中近景按距离和屏幕占用提高到 L1；普通选中、搜索定位和相机靠近都不自动请求 L2。属性面板提供“查看精细模型”，只在用户明确操作后请求该设备的 L2。范围未确定的设备也自动加载可支持几何，属性和树保留“范围未确定”说明。新表示完成前继续显示旧表示，分级不改变对象身份、选择身份或层级。

设备模板编译可在最多两个 Worker 中与 IFC 并行；场景放置等待首个 IFC 的真实坐标基准。冷编译和暖恢复使用同一放置链，共享 DEV 模板产生独立实例，递归 PHM 保留逐边矩阵、颜色和装配路径。当前视图先补齐基础表示再升级细节，后台继续补全全站基础表示。状态栏独立显示已处理、已显示、失败数量及当前阶段，悬停查看范围索引、模板编译和缓存等诊断；处理结束但有失败时明确提示，不能永久停在准备中或冒充成功。基础表示就绪不等于全类型精确重建，空来源和不支持类型保留明确诊断。能力边界见 [XML MOD](schema/substation-mod.md)，同 UUID 的 GL 文件仍是可选辅助来源。

属性中可显示几何状态和冷/暖来源。`empty`、`unsupported`、`partial` 与运行失败具有不同含义；完整加载阶段完成也不意味着所有源图元都已渲染。

三维视图支持选择、高亮和定位。空间语义索引提供 IFC 空间节点、对象和来源关联；属性集、数量、材料等详细内容按需读取。推断链接保留证据强度。

“更多”菜单提供仅看选中、恢复全站、恢复整站远景和上一视角；视角历史在当前工程会话内最多保存 20 个快照，并同时记录可见性筛选。快速移动后可立即返回；恢复失败时保留历史供重试，重复返回不额外弹出历史，工程切换取消旧返回。“仅看选中”使用源对象身份统一限制 DEV 与 IFC 各层表示，清空选择后保持空画面；恢复全站保留用户图层开关。多义来源不自动补关联，边界验收状态见[问题清单 O-05](open-issues.md)。状态栏可暂停自动后台细化，基础表示与连接线任务继续运行；明确请求的精细模型仍可进入优先队列。工程切换时清空这些会话状态。

### 单线图

存在 SCH/STD/SLD 时加载逻辑模型和单线图；缺失时三维与属性功能继续可用。STD 为 SVG 内容时不生成 STD 电气层级。单线图通过净化后的 SVG 图像呈现， 具有有效关联的 gridId 可参与选择联动；不能宣称任意对象都能一一关联。 格式与内容分型见 [逻辑模型](schema/logical-model.md)。

## 线路工程

### 地图与联动

地图显示有效塔位、导线/地线关系和跨越对象，树与地图可双向定位选择。

线路导航中的跨越物类型从实际 CROSS 叶对象自身 FAM 键族识别，支持电力线、房屋、树木、公路、铁路、河流和地下通信电缆。空属性值仍参与键存在判型；未知/冲突明确保留。分组标题汇总叶对象类型，原始 CODE 单独保存，不作为分类依据。桌面继续采用原有 F4 跨越分组及地图关系口径，不改变对象数量；规则见 [语义模型](schema/semantic-model.md#线路-cross-被跨越物类型)。

塔位以 CBM 的 BLHA 等来源字段建立，POINT_LINE MOD 中的点是其局部对象的点，不能全部计为杆塔。边界共享节点按来源路径复用，引用关系保留。

地图工作区是二维工程地图。杆塔 HNum/MOD 可在来源视图提供局部骨架预览，这不等于完整线路或杆塔三维模型。没有可预览数据时应安全降级。

属性按概览、参数、关系和来源组织，支持工程内搜索、地图截图与 CSV 输出。

原线路长度、几何测量长度、回路数量、导线数量各有独立口径，不能相互替代。

### 底图

当前默认采用 OSM 在线底图；配置天地图 Key 后可使用对应底图，服务异常时回退 OSM 或 Canvas。 Canvas 保留工程覆盖层的基本交互，不提供地理影像。 底图选择保存在 localStorage，重新打开线路工程不重置为默认；少量瓦片错误不会销毁已加载的 MapLibre 地图。 MapLibre load 超过 5 秒时仍激活透明 overlay，按工程 bbox 定位并校正容器尺寸，避免 Canvas-only 永久遮挡在线底图。OSM 图层下垫一层同源 OSM 数据的 CARTO 栅格：官方瓦片整块超时/限流时仍能显示底图，OSM 正常时被上层完全覆盖；容器尺寸变化通过 ResizeObserver 触发 `map.resize()`。 Key 保存在本地 SQLite 的 `app_setting` 表，不写入构建产物；保存后当前线路工程立即刷新卫星/地形/矢量按钮可用性，底图切换提示只写状态栏，不再拉起中央加载遮罩。 底图使用保留服务署名，不进行后台批量下载或离线打包。

### 弧垂

当前导线曲线是二维视觉示意，使用采样近似及缺省值，不能用于工程净空、张力或施工放样。
`KVALUE`、挂点和 `MATRIX0` 来源可供审计，不能把现有示意算法宣称为已核验的设计悬链线公式。
四类线路 MOD 与字段边界见 [线路 MOD](schema/powerline-mod.md)。

## 能力限制

本文件描述桌面端；Android 线路应用的当前实现与验收边界见 [移动端规格](mobile-spec.md)。 外部业务插件、坐标核验闭环和独立线路三维仍未实现。 线路底图仅支持 OSM/天地图在线服务与 Canvas 兜底。完整 Fragments 缓存默认关闭；IFC 浏览 LOD 的独立派生缓存与设备 LOD 派生缓存默认使用，三者的精度与版本契约各自独立。 以上能力的实现边界以本文件为准；未关闭缺陷与已接受限制见 [问题与限制](open-issues.md)。

当前正确性证据范围见 [验证](validation.md)，性能声明必须符合 [性能](performance.md) 的测量口径。

变电工程默认使用三维视口，线路地图初始化任务随工程切换取消。状态栏分别显示按业务规则识别且合并确定别名后的设备节点数，以及物理几何实例的处理进度；后者包含部件、导体等对象，不代表独立设备台数，也不等于唯一 DEV 文件数或 Mesh 数。未分类对象不计入业务设备数，其几何仍正常请求。所有物理实例自动请求基础表示；L0 场景提交不等待相机停止，L1 等精化提交在相机移动时最多延后 1 秒，选中设备优先，已有表示持续显示。提交仍受每轮时间预算约束。

变电工程业务树采用“安装工程 / 建筑工程”：安装侧按主变压器系统、电压配电装置（电压从高到低）、无功补偿、站用电、电缆及接地、二次组织，再下分间隔/功能单元及设备、附件和材料；建筑侧按实际建筑/构筑物、楼层、给排水、照明、消防和基础组织。设备直接展示，不增加“设备与附件”层；母线各段在所属配电区域合为一个母线设备间隔，母联、分段及进出线保留各自来源身份。归属状态（明确/推断/共享/待确认）在属性中查看，不形成“待确认”层级。分类不改变物理几何种子或可见性。

业务树只在明确对象级关联时合并 DEV/IFC 来源，保留原始路径及身份；同名间隔不合并，匿名来源不冒充真实建筑。材料、设备和建筑的推断受类型、范围、端点、距离及候选区分度约束，推断不升级为工程事实；没有人工审定真值时，不宣称归属准确率。业务对象数不是设备台数或工程量。区域和间隔按成员集合选择、定位与隔离恢复；设备与 IFC 叶子沿用现有检查器和普通 L0/L1 浏览路径。具体排序、证据阈值和验证边界见[业务树实现](impl/model-tree-business.md)。

状态栏设备节点数包含装配内部的独立功能单元，可能多于整机几何根数，两者不作进度分子分母。IFC 显示实际冷转换和暖恢复文件数，DEV 显示实际冷编译和暖恢复模板数；同一来源不同 LOD 仍分别计量。当前视图完成不要求全站均生成最高细节，失败明确作为部分失败完成显示，后台基础表示另列进度。

设备暖恢复对同时请求的模板作有界批读，复用同一 DEV/LOD 模板供多个装配实例放置。场景继续分批提交以保持输入响应，不把全站 GLB 或全部 LOD 强行合并为一个大文件。状态详情与诊断包含缓存批数、条目数和当前等待原因，逐个出现的实例不能单独作为缓存未命中的证据。

钢结构板件、杆件和紧固件的近景请求可使用依赖子集求值，减少连续区域中的整源重开。子集保留来源单位、放置、外观及未省略开洞；其他类型或无法验证的输入继续完整源求值。首次未缓存近景仍需打开完整来源，较大的区域仍有依赖构建和几何开销，不能保证即时完成。

IFC 近景几何与按需源属性缓存有容量和条目上限，淘汰后按来源重新生成。容量账升级会一次清退旧近景/属性条目，保留远景和语义缓存；升级后的首次近景加载可能重新计算。DEV 输入读取与解析使用共享预留预算，工程关闭会取消尚未取得预算的请求，已有表示保持到新表示可提交。
